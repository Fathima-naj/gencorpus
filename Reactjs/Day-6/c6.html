React - Day 6

State & useState Hook

1. What is State?

State is a built-in feature in React used to store and manage data that can change over time inside a component.

  • State makes components dynamic
  • It stores values like numbers, text, arrays, objects, etc.
  • When state changes → React automatically updates (re-renders) the UI

Example: Counter value, form input, toggle button, theme switch

// Normal variable ❌ let count = 0; // UI will NOT update when changed count = count + 1;

Why state? Normal variables do not tell React to re-render. State tells React: "Hey! Something changed → update UI"

Key Point: State is private to the component where it is defined.

2. useState Hook Basics

useState is a React Hook that allows functional components to use state.

import { useState } from "react"; function Counter(){ const [count, setCount] = useState(0); return ( <div> <p>{count}</p> </div> ); }
  • count → current state value
  • setCount → function to update state
  • useState(0) → initial value is 0

Important:

  • useState always returns an array → [value, setter]
  • You can name them anything (but follow convention)
// Naming convention const [data, setData] = useState();

3. Updating State

State is updated using the setter function.

  • Calling setter function updates state
  • React schedules a re-render
  • UI updates with new value

Best Practice (Very Important):

// Recommended way setCount(prev => prev + 1);

👉 This is safer because React updates can be asynchronous.

Multiple Updates Example:

// ❌ May give wrong result setCount(count + 1); setCount(count + 1); // ✅ Correct setCount(prev => prev + 1); setCount(prev => prev + 1);

4. Multiple State Variables

You can create multiple state variables inside a component.

const [name, setName] = useState(""); const [age, setAge] = useState(0);
  • Each state is independent
  • Updating one state does NOT affect others

Alternative (Object State):

const [user, setUser] = useState({ name: "", age: 0 });

Updating object state:

setUser({...user, name: "Fathima"});

👉 Use spread operator to avoid losing other values.

5. State Immutability

State should NOT be modified directly. Always create a new value.

// ❌ Wrong (direct mutation) count = count + 1; // ❌ Wrong (object mutation) user.name = "Fathima"; // ✅ Correct setCount(count + 1); // ✅ Correct (object) setUser({...user, name: "Fathima"});

Why? React uses comparison (old vs new state) to detect changes.

  • If you mutate directly → React may NOT detect change
  • If you create new value → React re-renders correctly

Golden Rule: Never mutate state directly ❗

6. Types of State

// Number const [count, setCount] = useState(0); // String const [name, setName] = useState(""); // Boolean const [isOn, setIsOn] = useState(false); // Array const [items, setItems] = useState([]); // Object const [user, setUser] = useState({});

Summary

  • State stores dynamic data
  • useState creates state in functional components
  • Always use setter function to update
  • State updates cause re-render
  • Never mutate state directly
