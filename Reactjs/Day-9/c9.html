React Forms

🔹 Handling Multiple Inputs

In React, we handle multiple form inputs using a single state object. Each input should have a name attribute. 

const [formData, setFormData] = useState({
  name: "",
  email: "",
  password: ""
});

const handleChange = (e) => {
  const { name, value } = e.target;

  setFormData({
    ...formData,
    [name]: value
  });
};

👉 This approach avoids creating separate state variables for each input.

🔹 Form Submission

React uses onSubmit to handle form submission. 

const handleSubmit = (e) => {
  e.preventDefault(); // prevent page reload

  console.log(formData);
};

👉 Always use e.preventDefault() to stop default HTML behavior.

🔹 Validation Logic

Validation ensures user inputs are correct before submission. It helps prevent empty fields, invalid formats, and weak data.

🔹 Common Validations

  • Required fields check
  • Email format validation (using Regex)
  • Password length validation

🔹 Example with Improved Logic

const validate = () => {
  let errors = {};

  // Regex for Email Validation
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

  // Required Field Validation
  if (!formData.name || formData.name.trim() === "") {
    errors.name = "Name is required";
  }

  if (!formData.email || formData.email.trim() === "") {
    errors.email = "Email is required";
  } 
  else if (!emailRegex.test(formData.email)) {
    errors.email = "Invalid email format";
  }

  if (!formData.password || formData.password.trim() === "") {
    errors.password = "Password is required";
  } 
  else if (formData.password.length < 6) {
    errors.password = "Password must be at least 6 characters";
  }

  return errors;
};

🔹 Explanation

  • Required Check: Ensures field is not empty using trim()
  • Regex: Validates correct email structure
  • test(): Returns true if email matches pattern
  • Errors Object: Stores messages for each invalid field

🔹 Example Email Regex Breakdown

/^[^\s@]+@[^\s@]+\.[^\s@]+$/
  • ^[^\s@]+ → Text before @
  • @ → Must contain @ symbol
  • [^\s@]+ → Domain name
  • \. → Dot (.)
  • [^\s@]+$ → Domain extension (like .com)

🔹 Error Messages

Store errors in state and display them dynamically. 

const [errors, setErrors] = useState({});

const handleSubmit = (e) => {
  e.preventDefault();

  const validationErrors = validate();

  if(Object.keys(validationErrors).length > 0){
    setErrors(validationErrors);
  } else {
    console.log("Form Submitted");
  }
};

👉 Display errors in UI: 

{errors.name && <p>{errors.name}</p>}

🔹 Controlled Components (Best Practices)

  • Always store input values in state
  • Use value + onChange
  • Never manipulate DOM directly
  • Keep form state in a single object (for large forms)
  • Validate before submitting
<input
  type="text"
  name="name"
  value={formData.name}
  onChange={handleChange}
/>
