⚛️ React useReducer Hook

Advanced State Management

1. What is useReducer?

useReducer is a React Hook used for managing complex state logic in components. It is an alternative to useState.

  • Best for complex state logic
  • Handles multiple state updates
  • Centralized state logic using reducer function

Basic Syntax

const [state, dispatch] = useReducer(reducer, initialState);
  • state → current state
  • dispatch → function to update state
  • reducer → logic to update state

2. useReducer vs useState

  • useState: Simple state (counter, toggle)
  • useReducer: Complex state (multiple values, logic)
// useState const [count, setCount] = useState(0); // useReducer const [state, dispatch] = useReducer(reducer, {count:0});
👉 Use useReducer when state logic becomes complex

3. Reducer Function

Reducer is a function that decides how state changes based on an action.

function reducer(state, action){ switch(action.type){ case "INCREMENT": return {count: state.count + 1}; case "DECREMENT": return {count: state.count - 1}; default: return state; } }
  • Takes state and action
  • Returns new state

4. Actions

Actions are objects that describe what should happen.

{ type: "INCREMENT" } { type: "DECREMENT" }
  • Must have a type
  • Can include extra data (payload)
{ type: "ADD", payload: 5 }

5. Dispatching Actions

Dispatch is used to send actions to the reducer.

  • Triggers reducer
  • Updates state

6. Full Example (Counter)

const initialState = { count: 0 }; function reducer(state, action){ switch(action.type){ case "INC": return {count: state.count + 1}; case "DEC": return {count: state.count - 1}; default: return state; } } function Counter(){ const [state, dispatch] = useReducer(reducer, initialState); return ( <div> <h2>{state.count}</h2> <button onClick={() => dispatch({type:"INC"})}>+</button> <button onClick={() => dispatch({type:"DEC"})}>-</button> </div> ); }

7. Combining useReducer + Context

You can combine useReducer with Context to create global state management.

const AppContext = createContext(); function AppProvider({children}){ const [state, dispatch] = useReducer(reducer, initialState); return ( <AppContext.Provider value={{state, dispatch}}> {children} </AppContext.Provider> ); }
  • Global state management
  • No prop drilling
👉 This pattern is used in real-world apps

8. When to Use useReducer?

  • Complex state logic
  • Multiple related states
  • State depends on previous state
  • Managing global state (with Context)

🛠 Practice: Global Counter App

  • Create a counter using useReducer
  • Add buttons: Increment, Decrement, Reset
  • Use Context to make counter global
  • Access counter in multiple components
dispatch({ type: "RESET" });

Summary

  • useReducer → advanced state management
  • Reducer → handles logic
  • Action → describes update
  • Dispatch → triggers update
  • Works great with Context
