React - Conditional Rendering & Lists

🔹 Conditional Rendering

Conditional rendering means showing different UI based on conditions (like if, true/false).

1. Using if statement (Expanded)

The if statement is used when you want to return completely different UI based on a condition.

Important: You cannot use if directly inside JSX. It must be used before the return statement.

🔹 Basic Example

function App() {
const isLoggedIn = true;

if (isLoggedIn) {
return <h1>Welcome User</h1>;
} else {
return <h1>Please Login</h1>;
}
}

👉 If isLoggedIn is true → "Welcome User" is shown

👉 If false → "Please Login" is shown

🔹 Example with Variable

function App() {
  const isLoggedIn = false;
  let message;

if (isLoggedIn) {
message = "Welcome Back!";
} else {
message = "Please Login First";
}

return <h2>{message}</h2>;
}

👉 Here we store result in a variable and render it inside JSX.

🔹 Example with Multiple Conditions

function App() {
  const user = "admin";

if (user === "admin") {
return <h1>Admin Dashboard</h1>;
} else if (user === "user") {
return <h1>User Dashboard</h1>;
} else {
return <h1>Guest Page</h1>;
}
}

👉 You can use else if for multiple conditions.

🔹 When to Use if Statement?

  • When you need full control over rendering
  • When returning completely different UI
  • When logic is complex

⚠️ Common Mistake

return (
  <div>
    if(isLoggedIn){   // ❌ WRONG
      <h1>Welcome</h1>
    }
  </div>
)

❌ You cannot write if inside JSX like this.

✅ Instead, use:

  • if outside return
  • && operator
  • ternary operator

2. Using && (AND operator)

Used when you want to show something only if condition is true.

function App() {
  const isLoggedIn = true;

return (


isLoggedIn && <p>Welcome back!</p>


);
}

👉 If condition is false, nothing will render.

3. Using Ternary Operator

Best for if-else inside JSX.

function App() {
  const isLoggedIn = false;

return (


{isLoggedIn ?
<h1> Dashboard </h1> :
<h1> Login Page </h1>
}


);
}

🔹 Rendering Lists (Arrays)

In React, we use the map() function to display lists (arrays) dynamically. Instead of writing elements manually, React can generate them automatically from data.

🔹 Basic Example

function App() {
  const fruits = ["Apple", "Banana", "Mango"];

return (
 <ul>
{fruits.map((item) => (
 <li>{item}</li>
))}
 </ul>
);
}

👉 Each array item becomes one <li> element.

🔸 How map() Works

  • Loops through each item in the array
  • Runs a function for every item
  • Returns JSX (HTML-like code)
  • Creates multiple elements dynamically

🔹 Using Index (Second Parameter)

You can also access the index of each item.

{fruits.map((item, index) => (
  <li>
    {index + 1}. {item}
  </li>
))}

👉 Output: 1. Apple, 2. Banana, 3. Mango

🔹 Rendering Objects in Array

Often, arrays contain objects instead of simple strings.

const users = [
  { id: 1, name: "Ali" },
  { id: 2, name: "Sara" }
];

return (
 <ul>
{users.map((user) => (
<li>{user.name}</li>
))}
</ul>
);

👉 Access object properties using user.name

🔹 Conditional Rendering Inside map()

You can apply conditions while rendering lists.

{fruits.map((item) => (
  item === "Banana" ? 
    <li>🍌 {item}</li> : 
    <li>{item}</li>
))}

👉 Adds special UI for Banana.

🔹 Empty List Handling

{fruits.length === 0 ? (
  <p>No items found</p>
) : (
  <ul>
    {fruits.map((item, index) => (
      <li key={index}>{item}</li>
    ))}
  </ul>
)}

👉 Shows message when array is empty.

🔹 When to Use map()

  • Displaying lists (todos, users, products)
  • Rendering dynamic data from API
  • Creating reusable UI components

🔹 Keys & Why They Matter

Keys help React identify which item changed, added, or removed.

❌ Without Key (Wrong)

{fruits.map((item) => (
  <li>{item}</li>
))}

✅ With Key (Correct)

{fruits.map((item, index) => (
  <li key={index}>{item}</li>
))}

👉 Best practice: Use unique ID instead of index when possible.

🛠 Todo List App

import React, { useState } from "react";

function App() {

  const [input, setInput] = useState("");
  const [todos, setTodos] = useState([]);
  const [editIndex, setEditIndex] = useState(null);

  // Add or Update Todo
  const handleAdd = () => {
    if(input.trim() === "") return;

    if(editIndex !== null){
      const updatedTodos = [...todos];
      updatedTodos[editIndex].text = input;
      setTodos(updatedTodos);
      setEditIndex(null);
    } else {
     setTodos([...todos, { id: Date.now(), text: input }]);
    }

    setInput("");
  };

  // Delete Todo
  const handleDelete = (index) => {
    const newTodos = todos.filter((_, i) => i !== index);
    setTodos(newTodos);
  };


  // Edit Todo
  const handleEdit = (index) => {
    setInput(todos[index].text);
    setEditIndex(index);
  };

  return (
    <div>

      <input 
        type="text" 
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="Enter task"
      />

      <button onClick={handleAdd}>
        {editIndex !== null ? "Update" : "Add"}
      </button>

      {todos.length === 0 ? (
        <p>No tasks available</p>
      ) : (
        <ul>
          {todos.map((todo, index) => (
            <li key={todo.id}>

              <span 
              
              >
                {todo.text}
              </span>

              <button onClick={() => handleEdit(index)}>Edit</button>
              <button onClick={() => handleDelete(index)}>Delete</button>

            </li>
          ))}
        </ul>
      )}

    </div>
  );
}

export default App;

✨ Features Included:

  • Add new todo
  • Edit existing todo
  • Delete todo
  • Shows "No tasks available" when empty

💡 Try Enhancing:

  • Add localStorage (save todos)
  • Add filters (All / Completed / Pending)
  • Add animations
