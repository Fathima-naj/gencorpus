⚡ React Performance Optimization

Make Your Apps Faster & Efficient

1. Why Optimization Matters?

Performance optimization improves speed, responsiveness, and user experience of your React application.

  • Faster UI rendering
  • Better user experience
  • Reduced unnecessary computations
  • Efficient resource usage
👉 Without optimization, apps may feel slow and laggy
---

2. React.memo

React.memo prevents a component from re-rendering if its props have not changed.

const MyComponent = React.memo(function MyComponent(props){ return <h2>{props.name}</h2>; });
  • Works like PureComponent
  • Shallow comparison of props
👉 Use when component receives same props frequently
---

3. useCallback

useCallback memoizes a function so it does not get recreated on every render.

const handleClick = useCallback(() => { console.log("Clicked"); }, []);
  • Prevents unnecessary function recreation
  • Useful with React.memo
---

4. useMemo

useMemo memoizes computed values to avoid expensive recalculations.

const result = useMemo(() => { return expensiveCalculation(num); }, [num]);
  • Used for heavy computations
  • Recomputes only when dependencies change
---

5. Avoiding Unnecessary Re-renders

  • Use React.memo for components
  • Use useCallback for functions
  • Use useMemo for calculations
  • Avoid inline functions in JSX
  • Keep state minimal
// ❌ Causes re-render
---

6. Lazy Loading & Code Splitting

Lazy loading loads components only when needed.

import React, { Suspense, lazy } from "react"; const About = lazy(() => import("./About")); function App(){ return ( <Suspense fallback="Loading..."> <About /> </Suspense> ); }
  • Reduces initial bundle size
  • Improves load time
---

7. When to Optimize?

  • When app becomes slow
  • Large lists or heavy calculations
  • Frequent re-renders
👉 Do not over-optimize small apps
---

🛠 Practice: Optimize Slow Component

  • Create a component with heavy calculation
  • Observe slow rendering
  • Apply useMemo to optimize
  • Wrap child component with React.memo
  • Use useCallback for functions
const slowValue = useMemo(() => heavyFunction(num), [num]);
---

Summary

  • React.memo → prevents re-render
  • useCallback → memoizes function
  • useMemo → memoizes value
  • Lazy loading → improves load time
