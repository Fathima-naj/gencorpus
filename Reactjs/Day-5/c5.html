React Props

1. What are Props?

Props (short for Properties) are used to pass data from one component to another in React.

They work similarly to function parameters in JavaScript. Just like you pass values to a function, you pass data to components using props.

Props are read-only (immutable), meaning:

  • You cannot modify props inside the child component
  • If you try to change them, React will not allow it
  • They ensure predictable data flow (one-way data flow)

🔹 Example

function Welcome(props) {
  return <h1>Hello {props.name}</h1>;
}
  • Props come from the parent component
  • Child components only "use" the data
  • This makes debugging easier

2. Passing Data Between Components

React follows unidirectional (one-way) data flow:

  • Data flows from Parent → Child
  • Child cannot directly modify parent data

🔹 Example

// Parent Component
function App() {
  return <User name="Fathima" age={22} />;
}

// Child Component
function User(props) {
  return (
    <div>
      <p>Name: {props.name}</p>
      <p>Age: {props.age}</p>
    </div>
  );
}

Important Notes

  • String props → written inside quotes
  • Number/boolean/JS expressions → inside { }
  • You can pass arrays, objects, and functions as props

🔹 Advanced Example (Passing Function)

function App() {
  function handleClick() {
    alert("Button clicked!");
  }

  return <Button onClick={handleClick} />;
}

function Button(props) {
  return <button onClick={props.onClick}>Click</button>;
}

3. Props Destructuring

Destructuring is a JavaScript feature that extracts values from objects.

🔹 Without Destructuring

function User(props) {
  return <p>{props.name}</p>;
}

🔹 With Destructuring

function User({ name, age }) {
  return (
    <div>
      <p>Name: {name}</p>
      <p>Age: {age}</p>
    </div>
  );
}

🔹 Destructuring Inside Function Body

function User(props) {
  const { name, age } = props;
  return <p>{name}</p>;
}

💡 Benefits

  • Cleaner code
  • Better readability
  • Less repetition

4. Default Props

Default props provide fallback values when no prop is passed.

🔹 Example

function User({ name = "Guest" }) {
  return <h2>Hello {name}</h2>;
}

Why Important?

  • Prevents undefined errors
  • Improves user experience
  • Makes components more reliable

🔹 Old Method

User.defaultProps = {
  name: "Guest"
};

⚠️ Note

Default props method is less used in modern functional components. Prefer destructuring.

5. PropTypes (Type Checking)

PropTypes help validate the type of props passed to a component.

🔹 Why Use It?

  • Catches bugs early
  • Improves code maintainability
  • Acts as documentation

🔹 Example

import PropTypes from 'prop-types';

function User({ name, age }) {
  return <p>{name} - {age}</p>;
}

User.propTypes = {
  name: PropTypes.string,
  age: PropTypes.number
};

🔹 Common Types

  • string
  • number
  • bool
  • array
  • object
  • func

🔹 Required Props

User.propTypes = {
  name: PropTypes.string.isRequired
};

6. Reusability Using Props

Props allow you to create dynamic and reusable components.

🔹 Example

function Button({ text }) {
  return <button>{text}</button>;
}

<Button text="Login" />
<Button text="Signup" />

Real-World Use

  • Cards
  • Buttons
  • Forms
  • Modals

💡 Key Idea

Instead of creating multiple components, create one reusable component and change data using props.

7. 🛠 Mini Task: Product Card Using Props

Create a reusable UI component for products.

🔹 Product Component

function ProductCard({ title, price, image }) {
  return (
    <div className="card">
      <img src={image} alt={title} width="150" />
      <h3>{title}</h3>
      <p>₹{price}</p>
      <button>Buy Now</button>
    </div>
  );
}

🔹 Using Product Component

function App() {
  return (
    <div>
      <ProductCard 
        title="Headphones" 
        price={1999} 
        image="img1.jpg" 
      />

      <ProductCard 
        title="Smart Watch" 
        price={2999} 
        image="img2.jpg" 
      />
    </div>
  );
}

Advanced Idea

const products = [
  { id: 1, title: "Phone", price: 15000 },
  { id: 2, title: "Laptop", price: 50000 }
];

products.map(product => (
  <ProductCard 
    key={product.id}
    title={product.title}

  />

📌 Final Summary

  • Props = data passed from parent to child
  • They are immutable
  • Enable component communication
  • Improve reusability
  • Support dynamic UI
  • Used everywhere in React apps
