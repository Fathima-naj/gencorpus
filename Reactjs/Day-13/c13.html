🛠 Assignment: Multi-Page Dashboard

Build a Multi-Page Dashboard application using React and React Router. This task will help you understand real-world routing, layouts, and API integration.

🎯 Objective

  • Understand routing in React
  • Work with dynamic pages
  • Fetch and display API data
  • Build a structured dashboard layout

📌 Tasks

1. Setup Routing

  • Install react-router-dom
  • Create routes for:
    • Home
    • About
    • Users
    • Dashboard
    • Login
---

2. Navigation

  • Create a Navbar
  • Use NavLink for navigation
  • Highlight active link
---

3. Route-Based Layout

  • Create a Layout.jsx
  • Add Navbar
  • Use <Outlet /> for page content
---

4. API Data Display

  • Fetch data from:
    https://jsonplaceholder.typicode.com/users
  • Display users list in Users page
  • Show name and email
---

5. Dynamic Routing

  • Create route: /user/:id
  • On clicking a user → navigate to details page
  • Display selected user ID or details
---

6. Nested Routes (Dashboard)

  • Create Dashboard page
  • Add nested routes:
    • Profile
    • Settings
  • Use Outlet inside Dashboard
---

7. Protected Routes

  • Create PrivateRoute
  • Allow access only if user is logged in
  • Otherwise redirect to Login page
---

8. Login & Redirect

  • Create Login page
  • After login → redirect to Dashboard
---

9. 404 Page

  • Create NotFound page
  • Show message: "Page Not Found"
---

10. Final Routing Structure

/ → Home /about → About /users → Users /user/:id → User Details /dashboard → Dashboard (Protected) /dashboard/profile /dashboard/settings /login → Login * → 404 Page
