Tailwind CSS with React

1. What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework used to build modern UI directly in HTML/JSX.

Instead of writing custom CSS, Tailwind provides small utility classes like: padding, margin, color, flex, grid etc.

👉 You combine these utilities to design UI.

🔹 Example

<div class="bg-blue-500 text-white p-4">
  Hello Tailwind
</div>

2. Why Tailwind? (Utility-First)

Traditional CSS: - Write separate CSS file - Name classes manually - Hard to maintain
Tailwind: - Write styles directly in JSX - No naming confusion - Faster development

🔹 Advantages

  • No CSS file needed
  • Faster UI development
  • Highly customizable
  • Responsive design built-in

3. Installing Tailwind in Vite React

📦 Step 1: Install

npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

📁 Step 2: Configure tailwind.config.js

export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}"
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}

🎨 Step 3: Add Tailwind to CSS

@tailwind base;
@tailwind components;
@tailwind utilities;

💡 Important

Tailwind scans your files and removes unused CSS → makes app fast.

4. Common Utility Classes

🔹 Flexbox

Flexbox is used to align and arrange items in a row or column.

Flex works on a parent-child relationship. The parent becomes a flex container and children become flex items. 

<div class="flex justify-center items-center h-40">
  Centered Content
</div>

🔹 Important Classes

  • flex → enables flexbox
  • flex-col → column layout
  • justify-center → horizontal alignment
  • items-center → vertical alignment
  • justify-between → space between items
  • gap-4 → space between children

💡 Real Use

Navbar, card layout, centering elements

🔹 Grid

Grid is used for 2D layouts (rows + columns).

Grid divides the container into columns and rows. You control how many columns and spacing. 

<div class="grid grid-cols-3 gap-4">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>

🔹 Important Classes

  • grid → enables grid
  • grid-cols-3 → 3 columns
  • gap-4 → space between items
  • col-span-2 → item spans 2 columns

💡 Flex vs Grid

  • Flex → 1D layout (row OR column)
  • Grid → 2D layout (row + column)

🔹 Spacing

Spacing controls margin and padding.

Tailwind uses a spacing scale: 1 = 0.25rem, 4 = 1rem, etc. 

p-4   → padding (all sides)
m-4   → margin (all sides)
mt-4  → margin-top
mb-4  → margin-bottom
px-4  → left + right padding
py-4  → top + bottom padding

💡 Real Use

Spacing improves UI readability and layout structure.

🔹 Colors

Tailwind provides a predefined color palette.

Colors follow a scale: 50 (light) → 900 (dark) 

bg-blue-500
text-white
border-gray-300
hover:bg-blue-600

🔹 Examples

  • bg-* → background color
  • text-* → text color
  • border-* → border color

💡 Real Use

Buttons, cards, themes, hover effects

🔹 Typography

Typography controls text styling.

Good typography improves readability and user experience. 

text-xl        → font size
font-bold      → font weight
text-center    → alignment
uppercase      → transform text

💡 Real Use

Headings, paragraphs, UI text styling

🔥 Combined Example

<div class="flex justify-between items-center bg-blue-500 text-white p-4">
  <h1 class="text-xl font-bold">Logo</h1>
  <button class="bg-white text-blue-500 px-4 py-2 rounded">
    Login
  </button>
</div>

Concepts used: Flex + Spacing + Colors + Typography

5. Responsive Design

Tailwind uses mobile-first approach.

🔹 Breakpoints

  • sm → small screens
  • md → tablets
  • lg → laptops
  • xl → large screens

🔹 Example

<div class="text-sm md:text-lg lg:text-2xl">
  Responsive Text
</div>

6. Reusable UI Patterns

Instead of repeating long class lists, you can create reusable components.

  <button class="bg-blue-500 text-white px-4 py-2 rounded">

7. 🛠 Practice: Responsive Card Layout

<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">

  <div class="bg-white shadow p-4 rounded">
    <h2 class="text-xl font-bold">Product</h2>
    <p>₹500</p>
  </div>

  <div class="bg-white shadow p-4 rounded">
    <h2 class="text-xl font-bold">Product</h2>
    <p>₹500</p>
  </div>

</div>

💡 What happens?

  • Mobile → 1 column
  • Tablet → 2 columns
  • Laptop → 3 columns
