⚛️ React useEffect Hook - Complete Guide

📌 What is useEffect?

useEffect is a React Hook used to perform side effects in functional components.

It runs code after the component renders. 

import { useEffect } from "react";

useEffect(() => {
  console.log("Component Rendered");
});
👉 Runs after every render by default

🔹 What are Side Effects?
Side effects are operations that affect things outside the component or don't directly return UI.

✅ Examples of Side Effects:
  • Fetching data from an API
  • Updating the DOM manually
  • Using timers (setTimeout / setInterval)
  • Adding event listeners
  • Local storage access
💡 React components should stay pure, so useEffect is used to handle these side effects separately.

🔄 React Lifecycle (with useEffect)

In class components, React had lifecycle methods like:

  • componentDidMount → runs after first render
  • componentDidUpdate → runs on updates
  • componentWillUnmount → cleanup before removal

A cleanup function is a function returned from useEffect that is used to stop or clean up side effects

when:

the component unmounts or before the effect runs again

👉 In functional components, useEffect replaces all of these.

1. componentDidMount (Mount)

useEffect(() => {
  console.log("Component Mounted");
}, []);
👉 Empty dependency array [] = runs only once (like componentDidMount)

2. componentDidUpdate (Update)

useEffect(() => {
  console.log("Component Updated");
}, [count]);
👉 Runs whenever dependency (count) changes

3. componentWillUnmount (Unmount)

useEffect(() => {
  return () => {
    console.log("Component Unmounted");
  };
}, []);
👉 Cleanup function = runs before component is removed

📦 Dependency Array

The second argument controls when useEffect runs.

1. No Dependency Array

useEffect(() => {
  console.log("Runs every render");
});
👉 Similar to componentDidUpdate + componentDidMount (runs always)

2. Empty Dependency Array []

useEffect(() => {
  console.log("Runs only once (on mount)");
}, []);
👉 Same as componentDidMount

3. With Dependencies

useEffect(() => {
  console.log("Runs when count changes");
}, [count]);
👉 Same as componentDidUpdate for specific values
👉 Always include dependencies to avoid bugs

🧹 Cleanup Function

Cleanup function is used to remove side effects like timers or event listeners. 

useEffect(() => {
  const timer = setInterval(() => {
    console.log("Running...");
  }, 1000);

  return () => {
    clearInterval(timer);
  };
}, []);
👉 Works like componentWillUnmount

🛠 Practice Examples

1. Timer Example

 import { useState, useEffect } from "react"; 
            function Timer() {
                 const [count, setCount] = useState(0);
                 useEffect(() => {
                    console.log("Effect started");

                    const interval = setInterval(() => {
                      console.log("Running interval");
                      setCount(prev => prev + 1);
                    }, 1000);

                    return () => {
                      console.log("Cleanup called");
                      clearInterval(interval);
                    };
                  }, []);
               
             return <h2>{count}</h2>; 
            }

2. API Call Example

                             }

📚 Summary

  • useEffect handles side effects
  • Dependency array controls execution
  • Replaces lifecycle methods
  • Cleanup prevents memory leaks
