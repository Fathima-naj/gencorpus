React API Integration

1. What is API Integration?

API Integration means connecting React frontend with backend to send and receive data.

2. fetch() vs axios

fetch()

fetch() is a built-in JavaScript function used to make HTTP requests. It returns a Promise.

fetch("https://api.example.com/users")
  .then(res => res.data)
  .then(data => console.log(data));

How it works:

  • fetch("url") → Sends a request to the server (default GET)
  • res → Response object (contains status, headers, etc.)
  • res.data → Converts response into usable JSON data
  • data → Final result you can use in your app

Important:

  • Does NOT automatically handle HTTP errors (like 404, 500)
  • You must manually check res.ok
  • Extra step needed to convert JSON

axios

axios is a popular external library used for making HTTP requests. It is easier and more powerful than axios().

import axios from "axios";

axios.get("https://api.example.com/users")
  .then(res => console.log(res.data));

How it works:

  • axios.get() → Sends GET request
  • res → Response object
  • res.data → Directly gives the actual data (no conversion needed)

Advantages:

  • Automatic JSON parsing
  • Better error handling (throws error for bad responses)
  • Cleaner and shorter code

Difference Summary

  • fetch → built-in, more manual work
  • axios → external, easier and cleaner

3. CRUD Operations (Using Axios)

Axios is commonly used in React projects because it provides cleaner syntax and better features compared to axios().

GET (Fetch Data)

import axios from "axios";

const getUsers = async () => {
const res = await axios.get("/users");
console.log(res.data);
};

POST (Create Data)

const createUser = async (user) => {
  await axios.post("/users", user);
};

PUT (Update Data)

const updateUser = async (id, user) => {
  await axios.put(`/users/${id}`, user);
};

DELETE (Remove Data)

const deleteUser = async (id) => {
  await axios.delete(`/users/${id}`);
};

Why Axios is Better Here

  • No need for JSON.stringify()
  • No need for res.data
  • Cleaner and shorter code
  • Better error handling

5. Handling Headers (Authorization Token)

In real-world React applications, APIs often require an Authorization token to access protected routes.

This token is usually sent inside the request headers using Bearer authentication.

Basic Example

import axios from "axios";

axios.get("/profile", {
headers: {
Authorization: "Bearer token"
}
});

How it works:

  • Authorization → Header key used for authentication
  • Bearer token → The access token received after login
  • Server checks token before allowing access to data

Real-world usage (Dynamic token)

const token = localStorage.getItem("token");

axios.get("/profile", {
headers: {
Authorization: `Bearer ${token}`
}
});
