⚛️ React Custom Hooks

Reusable Logic in React

1. What are Custom Hooks?

Custom Hooks are JavaScript functions that allow you to reuse logic across multiple components. They use built-in React Hooks like useState, useEffect, etc.

  • Start with use keyword
  • Reusable logic (not UI)
  • Helps avoid code duplication
👉 Example: useFetch, useForm, useToggle
---

2. Rules of Hooks

  • Only call Hooks at the top level (not inside loops/conditions)
  • Only call Hooks inside React functions or custom hooks
// ❌ Wrong if(true){ useState(); } // ✅ Correct const [count, setCount] = useState(0);
👉 Breaking rules may cause bugs or unexpected behavior
---

3. Creating a Custom Hook

A custom hook is just a function that uses other hooks.

function useCounter(){ const [count, setCount] = useState(0); const increment = () => setCount(count + 1); return { count, increment }; }
  • Reusable logic
  • Returns state + functions
---

4. Example: useFetch

Used to fetch API data.

import { useEffect, useState } from "react"; function useFetch(url){ const [data, setData] = useState([]); const [loading, setLoading] = useState(true); useEffect(() => { fetch(url) .then(res => res.json()) .then(data => { setData(data); setLoading(false); }); }, [url]); return { data, loading }; }
---

5. Example: useToggle

Used to toggle true/false values.

function useToggle(initial = false){ const [value, setValue] = useState(initial); const toggle = () => setValue(!value); return [value, toggle]; }
---

6. Example: useForm

Used to manage form inputs.

function useForm(initialValues){ const [values, setValues] = useState(initialValues); const handleChange = (e) => { setValues({ ...values, [e.target.name]: e.target.value }); }; return { values, handleChange }; }
---

7. When to Use Custom Hooks?

  • When logic is repeated in multiple components
  • API calls
  • Forms handling
  • Toggle logic
👉 Keeps components clean and reusable
---

🛠 Practice: Convert Logic into Custom Hook

  • Create a counter using useState
  • Convert it into useCounter hook
  • Use it in multiple components
// Before const [count, setCount] = useState(0); // After const { count, increment } = useCounter();
---

Summary

  • Custom Hooks → reusable logic
  • Must start with "use"
  • Follow rules of hooks
  • Used for API, forms, toggles
