React - Day 12

React Router

1. What is React Router?

React Router is a library that allows navigation between different pages (components) in a React app without reloading the page.

  • Creates Single Page Application (SPA)
  • No full page reload
  • Fast & smooth navigation
Real World Example: Instagram, Facebook → pages change without reload

Without Router ❌: Full page reload

With Router ✅: Only component updates

2. Installation & Setup

npm install react-router-dom
import { BrowserRouter } from "react-router-dom"; root.render( <BrowserRouter> <App /> </BrowserRouter> );
  • BrowserRouter → enables routing
  • Must wrap entire app
👉 Only ONE BrowserRouter should be used in app

3. Routes & Route

import { Routes, Route } from "react-router-dom"; <Routes> <Route path="/" element={<Home />} /> <Route path="/about" element={<About />} /> </Routes>
  • Routes → Wrapper for all routes
  • Route → Defines URL + Component

4. Nested Routes

<Route path="/dashboard" element={<Dashboard />}> <Route path="profile" element={<Profile />} /> </Route>
// Inside Dashboard.jsx import { Outlet } from "react-router-dom";
  • Outlet → placeholder for child routes

5. Link Navigation

import { Link } from "react-router-dom"; <Link to="/">Home</Link> <Link to="/about">About</Link>
  • Prevents page reload
  • Works like <a> tag but SPA friendly

6. NavLink (Active Styling)

import { NavLink } from "react-router-dom"; <NavLink to="/about" style={({isActive}) => ({ color: isActive ? "red" : "black" })} > About </NavLink>
  • Automatically detects active route
  • Used for navigation bars

7. Programmatic Navigation (useNavigate)

import { useNavigate } from "react-router-dom"; function Home(){ const navigate = useNavigate(); return ( <button onClick={() => navigate("/about")}> Go to About </button> ); }
  • Navigate using JS logic
  • Useful after form submit/login

8. Dynamic Routing (Params)

<Route path="/user/:id" element={<User />} />
import { useParams } from "react-router-dom"; function User(){ const { id } = useParams(); return <h2>User ID: {id}</h2>; }
  • Dynamic values in URL
  • Used for profiles, products, etc.

9. Query Parameters

// URL: /search?name=react import { useSearchParams } from "react-router-dom"; const [params] = useSearchParams(); const name = params.get("name");

10. 404 Page (Not Found)

<Route path="*" element={<NotFound />} />
  • Handles invalid routes

11. Protected Routes

function PrivateRoute({ children }){ const isAuth = true; return isAuth ? children : <Navigate to="/login" /> }
<Route path="/dashboard" element={ <PrivateRoute> <Dashboard /> </PrivateRoute> } />

13. Route-Based Layout

Route-based layout means creating a common layout (like Navbar, Sidebar, Footer) that stays the same across multiple pages, while only the inner content changes based on the route.

  • Used in dashboards and multi-page apps
  • Avoids repeating UI code
  • Uses Nested Routes + Outlet
Real World Example: Admin dashboard → Sidebar & Navbar stay fixed, content changes
// Layout.jsx import { Outlet } from "react-router-dom"; function Layout(){ return ( <div> <h1>Navbar</h1> <hr /> {/* Page Content Changes Here */} <Outlet /> <hr /> <h3>Footer</h3> </div> ); }
// App.jsx import { Routes, Route } from "react-router-dom"; import Layout from "./Layout"; <Routes> <Route path="/" element={<Layout />}> <Route index element={<Home />} /> <Route path="about" element={<About />} /> <Route path="dashboard" element={<Dashboard />} /> </Route> </Routes>
  • Layout Component → Common UI (Navbar, Footer)
  • Outlet → Dynamic content loads here
  • Nested Routes → child pages inside layout

Summary

  • React Router → navigation system
  • BrowserRouter → wraps app
  • Routes & Route → define pages
  • Link → navigation
  • NavLink → active styling
  • useNavigate → redirect
  • useParams → dynamic routing
  • Nested routes → layouts
  • Protected routes → security
