HTML - Day 4

1. Anchor Target Attribute

Specifies where to open the linked document.

<a href="page.html" target="_self">Same Tab</a> <a href="page.html" target="_blank">New Tab</a> <a href="page.html" target="_parent">Parent Frame</a> <a href="page.html" target="_top">Full Window</a>
  • _self → default (same tab)
  • _blank → new tab
  • _parent → parent frame
  • _top → full window

Anchor Target Working Example (_parent & _top)

This example shows how links behave inside nested iframes.

<!-- Outer iframe --> <iframe name="parentFrame" width="100%" height="300"></iframe> <!-- Inner iframe content (simulate another page) --> <!-- Imagine this is loaded inside parentFrame --> <iframe name="childFrame" width="100%" height="150"></iframe> <!-- Links inside child iframe --> <a href="https://example.com" target="_self"> _self → Opens inside child iframe </a> <br> <a href="https://example.com" target="_parent"> _parent → Opens in parent iframe </a> <br> <a href="https://example.com" target="_top"> _top → Opens full browser window </a>

2. _self vs _top in iframe

Controls where the link opens when using iframe.

<iframe name="frame1"></iframe> <a href="page.html" target="frame1">Open in iframe</a> <a href="page.html" target="_top">Open full page</a>
  • _self → inside iframe
  • _top → breaks iframe

3. Download Attribute

Used to download a file instead of opening it.

<a href="file.pdf" download>Download</a> <a href="file.pdf" download="notes.pdf"> Download with new name </a>

4. Navigate to Section

Used to jump to another section of the same page.

<a href="#section1">Go to Section</a> <h2 id="section1">Section 1</h2>

5. Pre Tag

The <pre> tag defines preformatted text.

Text in a <pre> element is displayed in a fixed-width font, and the text preserves both spaces and line breaks. The text will be displayed exactly as written in the HTML source code.
<pre> Hello World </pre>

6. Quote Tag (q)

Defines short inline quotation.

<p>He said <q>Hello</q></p>

7. Blockquote Tag

Defines long quotation.

<blockquote> This is a long quote </blockquote>

8. Abbr Tag

Defines abbreviation (shows full form on hover).

<abbr title="World Health Organization">WHO</abbr>

9. Favicon

Icon shown in browser tab.

<head> <link rel="icon" href="favicon.png"> </head>

10. HTML Entities

HTML entities are used to display reserved characters and special symbols in HTML.

Entities can be written in two ways:

  • Entity Name → &name;
  • Entity Number → &#number;

Reserved Characters

These characters have special meaning in HTML, so we use entities:

< → &lt; → &#60; > → &gt; → &#62; & → &amp; → &#38; " → &quot; → &#34; ' → &apos; → &#39;

👉 These are mainly used to display HTML code in browser.

Example

<p>This is a paragraph</p>

👉 Output shows the tag instead of executing it.

Non-Breaking Space (&nbsp;)

The &nbsp; entity is used to create extra spaces.

Hello&nbsp;&nbsp;&nbsp;World

👉 Output: Hello World

Common Symbols

&copy; → © → &#169; &reg; → ® → &#174; &euro; → € → &#8364; &pound; → £ → &#163; &yen; → ¥ → &#165; &dollar; → $ → &#36;

Mathematical Symbols

&plusmn; → ± → &#177; &times; → × → &#215; &divide; → ÷ → &#247;

Card Symbols

&hearts; → ♥ → &#9829; &spades; → ♠ → &#9824; &clubs; → ♣ → &#9827; &diams; → ♦ → &#9830;

Why Use HTML Entities?

  • To display reserved characters (<, >, &)
  • To show HTML code as text
  • To add symbols and special characters
  • To create extra spaces using &nbsp;

Important Notes

  • Not all entities have names, but all have numbers
  • Entity names are easier to remember
  • Numbers are more universal (browser safe)
