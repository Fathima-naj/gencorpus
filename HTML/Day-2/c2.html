HTML Forms

1. What is HTML Form?

An HTML form is used to collect user input such as name, email, password, etc.

The data entered in a form is usually sent to a server for processing.

<form>
  form elements go here
</form>

Note: All input elements must be inside the <form> tag.

2. Label

The <label> tag defines a label for an input element.

It improves accessibility and when clicked, it focuses the input field.

<label for="name">Name:</label>
<input type="text" id="name">

3. Textbox & maxlength

A textbox is created using type="text". It allows users to enter text.

The maxlength attribute limits the number of characters.

<input type="text" maxlength="10">

👉 User can enter only 10 characters.

4. Password Textbox

The password field hides user input for security.

<input type="password">

👉 Text appears as dots (••••).

5. Number Textbox (Min & Max)

The number input allows only numeric values.

min and max define the allowed range.

<input type="number" min="1" max="100">

👉 Only values between 1 and 100 are allowed.

6. Email Textbox

The email input is used to enter email addresses.

The browser automatically validates the format.

<input type="email">

👉 Example: user@gmail.com

7. Telephone Textbox

The telephone input is used to enter phone numbers.

<input type="tel">

👉 No strict validation by default.

8. Dropdown List

A dropdown list allows users to select one option from multiple choices.

<select>
  <option>HTML</option>
  <option>CSS</option>
  <option>JavaScript</option>
</select>

9. Checkbox

Checkboxes allow users to select multiple options.

<input type="checkbox"> HTML
<input type="checkbox"> CSS

10. Radio Button

Radio buttons allow the user to select only one option from a group.

Important: All radio buttons must have the same name to work as a group.

<input type="radio" name="gender"> Male
<input type="radio" name="gender"> Female

👉 Only one option can be selected at a time.

11. Important Attributes (name, id, for)

1. name Attribute

The name attribute is used to identify form data when it is submitted.

<input type="text" name="username">

👉 Data is sent to server as: username=value

---

2. id Attribute

The id attribute uniquely identifies an element.

<input type="text" id="user">

👉 Used for linking with label or JavaScript.

---

3. for Attribute (in label)

The for attribute connects label with input.

<label for="user">Username:</label>
<input type="text" id="user">

👉 Clicking label focuses input field.

12. How to Show Images

The <img> tag is used to display images in a webpage.

<img src="image.jpg" alt="Sample Image" width="200">

src → image path

alt → alternative text

13. Fieldset and Legend

The <fieldset> tag groups related form elements.

The <legend> tag gives a title to the group.

<fieldset>
  <legend>Personal Info</legend>
  Name: <input type="text">
</fieldset>

14. Anchor Tag

The <a> tag is used to create hyperlinks.

<a href="https://www.google.com">Visit Google</a>

👉 Clicking the link navigates to another page.
