Introduction to HTML

1. What is HTML?

HTML (HyperText Markup Language) is the standard language used to create and structure web pages.

🔹 What does HTML mean?

  • HyperText → Text that contains links to other pages (using links called hyperlinks).
  • Markup → Tags are used to "mark" or structure the content.
  • Language → A set of rules and syntax to write web pages.

🔹 Example of HyperText

<a href="https://www.google.com">Go to Google</a>

Here, clicking the link takes you to another webpage. That is why it is called HyperText.

🔹 What is Markup?

HTML uses tags to define elements and structure content.


<h1>Heading</h1>
<p>Paragraph</p>

Tags tell the browser how content should appear.

🔹 Key Features of HTML

  • Easy to learn and use
  • Platform independent (works on all browsers)
  • Used to create structure of web pages
  • Works with CSS (style) and JavaScript (functionality)

🔹 Example

<p>This is a paragraph</p>
HTML is not a programming language. It cannot perform logic like conditions or loops. It is only used for structuring content.

2. Frontend, Backend & Full Stack

🔹 Frontend (Client Side)

The frontend is the part of the website that users can see and interact with directly.

  • Design (UI - User Interface)
  • Buttons, forms, navigation menus
  • Layouts, colors, fonts

Technologies Used:

  • HTML → Structure
  • CSS → Styling
  • JavaScript → Interactivity

Example:


<button>Click Me</button>
When you click a button or fill a form, you are interacting with the frontend.

🔹 Backend (Server Side)

The backend is the part of the website that works behind the scenes.

  • Handles user data
  • Processes requests
  • Connects to databases
  • Authentication (login/signup)

Technologies Used:

  • Node.js
  • Python
  • Java
  • PHP
  • Databases (MongoDB, MySQL)

Example Flow:


User clicks "Login" → Data sent to server → Server checks database → Response sent back
Backend is not visible to users, but it powers the application.

🔹 Full Stack

A Full Stack Developer works on both frontend and backend.

  • Designs UI (frontend)
  • Builds server logic (backend)
  • Manages database

Example Stack:

  • MERN Stack:
    • MongoDB (Database)
    • Express.js (Backend framework)
    • React (Frontend)
    • Node.js (Runtime)
A full stack developer can build a complete web application from start to end.

3. HTML vs HTML5

HTML HTML5
Old version Latest version
Limited features Supports audio and video
No semantic elements Provides semantic tags like <header>, <footer>, <article>
Uses plugins for multimedia (Flash) No plugins required (built-in support)
No canvas or SVG support Supports <canvas> and SVG for graphics

5. W3C & Markup Language

🔹 What is W3C?

W3C (World Wide Web Consortium) is an international organization that develops standards for the web.

  • Creates rules and guidelines for web technologies
  • Ensures websites work consistently across all browsers

Examples of W3C Standards:

  • HTML
  • CSS
  • XML
W3C ensures that a webpage looks and works the same in Chrome, Firefox, Edge, etc.

🔹 What is a Markup Language?

A markup language is a system used to structure and format content using tags.

🔸 Why is it called "Markup"?

Because we "mark" the content with tags to define its structure.

🔸 Example:


<h1>This is a Heading</h1>
<p>This is a paragraph</p>

Here:

  • <h1> defines a heading
  • <p> defines a paragraph

🔸 Features of Markup Languages

  • Uses tags to structure content
  • Easy to read and write
  • Platform independent
  • Does not perform logic (no loops, conditions)

🔸 Examples of Markup Languages

  • HTML (HyperText Markup Language)
  • XML (Extensible Markup Language)
HTML is a markup language, not a programming language, because it only structures content and does not perform logical operations.
W3C creates the standards (rules), and markup languages like HTML follow those rules.

4. Basic HTML Structure


<!DOCTYPE html>
<html>
<head>
  <title>Page Title</title>
</head>

<body>
  <h1>Hello World</h1>
</body>

</html>

🔹 Explanation of Each Tag

  • <!DOCTYPE html>

    Declares the document type and tells the browser that this is an HTML5 document.

  • <html>

    The root element of the HTML page. All other elements are inside this tag.

  • <head>

    Contains metadata (information about the page) like title, links, styles, and scripts. This content is not visible on the webpage.

  • <title>

    Sets the title of the webpage, which appears in the browser tab.

  • <body>

    Contains all the visible content of the webpage such as text, images, headings, buttons, etc.

  • <h1>

    Defines the main heading. It is the most important heading on the page.

The <head> section is for configuration, while the <body> section is for displaying content to users.

HTML Elements

An HTML element is the complete structure from the opening tag to the closing tag, including the content inside.

🔹 Basic Structure of an Element


<tagname>Content</tagname>

Example:


<p>This is a paragraph</p>
  • <p> → Opening tag
  • Content → Text inside the element
  • </p> → Closing tag

🔹 Nested Elements

HTML elements can be placed inside other elements.


<p>This is <b>bold</b> text</p>

Here, the <b> element is inside the <p> element.

🔹 Empty Elements

Some elements do not have content and do not need closing tags.


<br>
<hr>
An HTML element usually has an opening tag, content, and a closing tag, but some elements are self-closing.

5. Text Formatting

HTML provides several elements for formatting text.

🔹 Examples

Bold Text

Important Text

Italic Text

Emphasized Text

Marked (Highlighted) Text

Smaller Text

Deleted Text

Inserted Text

🔹 Tag Explanation

  • <b> → Bold text (visual only)
  • <strong> → Important text (semantic meaning)
  • <i> → Italic text (visual only)
  • <em> → Emphasized text (semantic meaning)
  • <mark> → Highlights text
  • <small> → Displays smaller text
  • <del> → Shows deleted (strikethrough) text
  • <ins> → Shows inserted (underlined) text
  • <sub> → Subscript (below baseline)
  • <sup> → Superscript (above baseline)
Semantic tags like <strong> and <em> improve accessibility and SEO compared to <b> and <i>.

6. b vs strong

Both <b> and <strong> display text in bold, but they have different meanings.

<b> <strong>
Used only for visual bold styling Indicates important text (semantic meaning)
No importance for screen readers Screen readers give extra importance
No SEO benefit Improves accessibility and SEO

🔹 Example


<p><b>This is bold text</b></p>
<p><strong>This is important text</strong></p>
Use <strong> when the text is important, not just for styling.

7. i vs em

Both <i> and <em> display italic text, but they have different purposes.

<i> <em>
Used for visual italic styling Used to emphasize text
No semantic meaning Has semantic meaning
No effect on screen readers Screen readers stress the text

🔹 Example


<p><i>This is italic text</i></p>
<p><em>This is emphasized text</em></p>
Use <em> when you want to give importance or stress to the text.

8. Headings

HTML provides six levels of headings from <h1> to <h6>.

These are used to define titles and subtitles on a webpage.

🔹 Syntax


<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

🔹 Output Example

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

🔹 Explanation

  • <h1> → Main heading (most important, largest size)
  • <h2> → Subheading
  • <h3> → Section heading
  • <h4> → Sub-section heading
  • <h5> → Smaller heading
  • <h6> → Smallest heading (least important)

🔹 Important Points

  • They help structure content clearly
  • Use only one <h1> per page (best practice)
  • Do not skip heading levels (use in order)
Headings are not just for size. They give meaning and structure to your content, which helps both users and search engines.

9. Paragraph

The <p> tag is used to define a paragraph in HTML.

🔹 Syntax

<p>This is a paragraph</p>

🔹 Example

This is a paragraph.

This is another paragraph.

🔹 Key Features

  • Browsers automatically add space (margin) before and after paragraphs
  • Used to group related text content
  • Helps improve readability of web pages

🔹 Important Note

HTML ignores extra spaces and line breaks inside a paragraph. 


<p>
This    is
a    paragraph
</p>

👉 Output will be: "This is a paragraph"

Use the <br> tag if you want a line break inside a paragraph.

10. Line Break & Horizontal Line

HTML provides special tags to control line breaks and separate content.

🔹 Line Break (<br>)

The <br> tag is used to insert a line break without starting a new paragraph.

Example:


Line 1<br>Line 2

Output:

Line 1
Line 2

  • Used to break lines inside text
  • Does not need a closing tag (self-closing)
  • Commonly used in poems, addresses, etc.

🔹 Horizontal Line (<hr>)

The <hr> tag is used to create a horizontal line to separate content.

Example:


<hr>

Output:

  • Represents a thematic break between sections
  • Does not need a closing tag (self-closing)
  • Used to divide content visually
Use <br> for line breaks within text, and <hr> to separate sections of content.

12. Accessibility

Accessibility means designing websites so that everyone can use them, including people with disabilities such as visual, hearing, or motor impairments.

🔹 Why Accessibility is Important?

  • Helps visually impaired users using screen readers
  • Improves user experience for all users
  • Makes websites more inclusive
  • Improves SEO (Search Engine Optimization)

🔹 Best Practices

  • Use semantic tags like <header>, <nav>, <main>, <footer>
  • Use proper heading structure (<h1> to <h6> in order)
  • Use <strong> instead of <b> for important text
  • Use <em> instead of <i> for emphasis
  • Add alt attributes to images for screen readers

🔹 Example


<img src="image.jpg" alt="A beautiful beach">

The alt attribute helps screen readers describe the image to users who cannot see it.

Accessibility ensures your website is usable by everyone, including people using assistive technologies like screen readers.

13. Self Closing Tags

Self-closing tags (also called empty elements) are HTML elements that do not have any content and do not require a closing tag.

🔹 Syntax


<tagname>

These tags do not have a separate closing tag like </tagname>.

🔹 Examples


<br>
<hr>
<img src="image.jpg">
<input type="text">
<meta>
<link>

🔹 Explanation of Common Self-Closing Tags

  • <br> → Inserts a line break
  • <hr> → Creates a horizontal line
  • <img> → Displays an image
  • <input> → Creates input fields (forms)
  • <meta> → Defines metadata (inside <head>)
  • <link> → Links external resources (like CSS, favicon)

🔹 Important Points

  • They do not wrap content
  • They are written as a single tag
  • In HTML5, closing slash (/) is optional

<br>   
<br />
Self-closing tags are used when no content is needed inside the element.
