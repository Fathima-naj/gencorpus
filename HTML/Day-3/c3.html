HTML - Day 3

1. Marquee Tag

Used to create scrolling text (not recommended in modern HTML).

<marquee direction="right">Welcome to my website</marquee>

Direction values: left (default), right, up, down

<marquee direction="left">Left Scroll</marquee> <marquee direction="right">Right Scroll</marquee> <marquee direction="up">Up Scroll</marquee> <marquee direction="down">Down Scroll</marquee>

Scroll Speed (scrollamount):

<marquee scrollamount="5">Slow Speed</marquee> <marquee scrollamount="15">Fast Speed</marquee>

2. Iframe

Used to embed another webpage.

<iframe src="https://example.com" width="300" height="200"></iframe>

3. Block Level Elements

Block-level elements always start on a new line and take up the full width available. They create a "block" structure in the webpage.

Features:

  • Start on a new line
  • Take full width (100%)
  • Can contain other block and inline elements

Common Block Elements:

  • <div>
  • <p>
  • <h1> to <h6>
  • <section>
  • <article>
  • <header>
  • <footer>
  • <nav>
  • <ul>, <ol>, <li>
  • <form>
<div> <p>This is a block element</p> </div>

4. Inline Elements

Inline elements do not start on a new line. They only take up as much width as necessary. They are usually used to style or format small parts of content.

Features:

  • Do not start on a new line
  • Take only required width
  • Cannot contain block elements

Common Inline Elements:

  • <span>
  • <a>
  • <img>
  • <b>, <strong>
  • <i>, <em>
  • <mark>
  • <small>
  • <label>
  • <input>
<p> This is <span style="color:red">inline</span> text. </p>

Difference Between Block and Inline Elements

Block Element: <div>Hello</div> <div>World</div> Inline Element: <span>Hello</span> <span>World</span>

👉 In block elements, "Hello" and "World" appear on separate lines.
👉 In inline elements, they appear on the same line.

7. Radio Button

Radio buttons are used when the user needs to select only one option from a group.

Important:

  • All radio buttons in a group must have the same name attribute
  • This ensures only one option can be selected at a time
<input type="radio" name="gender"> Male <input type="radio" name="gender"> Female

With value attribute:

<input type="radio" name="gender" value="male"> Male <input type="radio" name="gender" value="female"> Female

Default selected option (checked):

<input type="radio" name="gender" value="male" checked> Male <input type="radio" name="gender" value="female"> Female

Using label for better usability:

<label> <input type="radio" name="gender" value="male"> Male </label> <label> <input type="radio" name="gender" value="female"> Female </label>

8. Text Area

The <textarea> element is used to create a multi-line input field. It is mainly used for long text such as comments, messages, or descriptions.

Features:

  • Allows multiple lines of text
  • Size can be controlled using rows and cols
  • Can be resized by the user (default behavior)
<textarea rows="4" cols="30"></textarea>

With placeholder text:

<textarea rows="4" cols="30" placeholder="Enter your message..."></textarea>

Default text inside textarea:

<textarea rows="4" cols="30"> This is default text </textarea>

Disable resizing:

<textarea style="resize: none;" rows="4" cols="30"></textarea>

Using name attribute (for form submission):

<form> <textarea name="message"></textarea> </form>

👉 When the form is submitted, the data is sent as:
message=your_text_here

9. Unordered List (ul)

The <ul> tag is used to create an unordered list. Items in the list are displayed with bullet points.

Features:

  • Displays items with bullets
  • Each item is defined using <li>
<ul> <li>Apple</li> <li>Banana</li> </ul>

Different bullet styles:

<ul style="list-style-type: disc;"> <ul style="list-style-type: circle;"> <ul style="list-style-type: square;"> <ul style="list-style-type: none;">

10. Ordered List (ol)

The <ol> tag is used to create an ordered list. Items are displayed in a numbered format.

Features:

  • Displays items with numbers or letters
  • Each item is defined using <li>
<ol> <li>Step 1</li> <li>Step 2</li> </ol>

Different numbering types:

<ol type="1"> <ol type="A"> <ol type="a"> <ol type="I"> <ol type="i">

Start from a specific number:

<ol start="5"> <li>Item</li> </ol>

Reversed list:

<ol reversed> <li>Item 1</li> <li>Item 2</li> </ol>

Nested List (List inside List)

<ul> <li>Fruits <ul> <li>Apple</li> <li>Mango</li> </ul> </li> </ul>

11. Search Input

The <input type="search"> is used to create a search field. It is similar to a text input but is specially designed for search functionality.

Features:

  • Used for search boxes
  • May show a clear (✖) button in some browsers
  • Behaves like a text input
<input type="search" placeholder="Search here">

With name attribute (for form submission):

<form> <input type="search" name="query" placeholder="Search..."> <button type="submit">Search</button> </form>

👉 When submitted, the data is sent as:
query=your_search_text

With required validation:

<input type="search" placeholder="Search..." required>

With default value:

<input type="search" value="HTML">

With autofocus:

<input type="search" placeholder="Search..." autofocus>

Difference from text input:

  • <input type="text"> → general input
  • <input type="search"> → specifically for search fields

18. Datalist

The <datalist> element provides a list of predefined options for an input field. It gives auto-suggestions as the user types.

Features:

  • Provides suggestions while typing
  • User can select from list or enter custom value
  • Works with the list attribute of <input>
<input list="browsers"> <datalist id="browsers"> <option value="Chrome"> <option value="Firefox"> <option value="Edge"> </datalist>

With placeholder:

<input list="browsers" placeholder="Choose browser">

Using name attribute (form submission):

<form> <input list="browsers" name="browser"> </form>

👉 When form is submitted, selected value is sent as:
browser=Chrome

Difference between select and datalist:

  • <select> → user must choose from given options
  • <datalist> → user can type or choose suggestion

Important Note:

  • <datalist> only provides suggestions (not strict selection)
  • Not fully supported in very old browsers

20. Video

The <video> tag is used to embed video content in a webpage. It supports different formats like MP4, WebM, and OGG.

Features:

  • Used to play videos in the browser
  • Supports controls like play, pause, volume
  • Can autoplay, loop, and mute
<video controls width="300"> <source src="video.mp4" type="video/mp4"> </video>

Common attributes:

<video controls autoplay muted loop width="300"> <source src="video.mp4" type="video/mp4"> </video>
  • controls → shows play/pause buttons
  • autoplay → plays automatically
  • muted → required for autoplay in many browsers
  • loop → repeats video

Multiple sources (for browser support):

<video controls width="300"> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> </video>

21. Audio

The <audio> tag is used to embed sound or music in a webpage. It supports formats like MP3, WAV, and OGG.

Features:

  • Used to play audio files
  • Supports controls like play, pause, volume
<audio controls> <source src="audio.mp3" type="audio/mpeg"> </audio>

Common attributes:

<audio controls autoplay muted loop> <source src="audio.mp3" type="audio/mpeg"> </audio>
  • controls → shows audio controls
  • autoplay → plays automatically
  • muted → starts with no sound
  • loop → repeats audio

Multiple sources:

<audio controls> <source src="audio.mp3" type="audio/mpeg"> <source src="audio.ogg" type="audio/ogg"> </audio>
