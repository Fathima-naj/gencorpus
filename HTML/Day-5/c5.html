HTML - Day 5

1. HTML Table

Used to display data in rows and columns.

<table border="1"> <tr> <th>Name</th> <th>Age</th> </tr> <tr> <td>Sara</td> <td>20</td> </tr> </table>
  • <table> → table container
  • <tr> → table row
  • <th> → table heading (bold & center)
  • <td> → table data

Table Borders

Normal Border:

<table border="1">...</table>

Collapsed Border:

<table style="border-collapse: collapse;" border="1">

Border Styles:

table, th, td { border: 2px solid black; } border-style: dotted dashed solid double groove ridge inset outset none hidden

Example:

table, th, td { border: 2px dashed red; }

Border Color:

table, th, td { border: 2px solid blue; }

Table Size

Column Width:

<table style="width:100%"> <th style="width:70%">Name</th>

Row Height:

<tr style="height:50px">

Table Headers

Vertical Header:

<tr> <th>Name</th> <td>Sara</td> </tr>

Align Header:

<th style="text-align:left">Name</th>

Header for Multiple Columns:

<th colspan="2">Details</th>

Table Caption:

<table> <caption>Student Table</caption> </table>

Padding & Spacing

Cell Padding (space inside cell):

th, td { padding: 10px; }

Cell Spacing (space between cells):

table { border-spacing: 10px; }

Colspan & Rowspan

Colspan (merge columns):

<td colspan="2">Merged Columns</td>

Rowspan (merge rows):

<td rowspan="2">Merged Rows</td>

2. Button Types

Normal Button

Does nothing by default.

<button type="button">Click Me</button>

Submit Button

Submits form data.

<form> <input type="text" name="name"> <button type="submit">Submit</button> </form>

Reset Button

Resets form fields to default values.

<form> <input type="text" value="Hello"> <button type="reset">Reset</button> </form>

3. Semantic HTML

Semantic elements clearly describe their meaning to browser and developer.

Examples:

  • <header>
  • <nav>
  • <main>
  • <section>
  • <article>
  • <footer>
<header>Header Content</header> <nav>Navigation</nav> <main> <section> <article>Article Content</article> </section> </main> <footer>Footer</footer>

4. Header

Defines the top section of a webpage.

<header> <h1>My Website</h1> </header>

5. Nav

Defines navigation links.

<nav> <a href="#">Home</a> <a href="#">About</a> </nav>

6. Main

Represents main content of the page.

<main> <p>Main Content</p> </main>

7. Article

Represents independent content.

<article> <h2>Blog Title</h2> <p>Blog content</p> </article>

8. Footer

Defines bottom section of a page.

<footer> <p>© 2026 My Website</p> </footer>

Why Use Semantic HTML?

  • Improves readability
  • Better SEO
  • Better accessibility
  • Easy for developers to understand
