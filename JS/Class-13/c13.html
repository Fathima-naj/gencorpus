Forms & Events

Forms are used to collect user input such as login credentials, search queries, contact information, and registrations. JavaScript allows us to read form data, validate it, show errors, and control submission behavior.

2. Handling Form Submission

Forms automatically reload the page when submitted. To control submission behavior we use the submit event.

Prevent Default Form Submission

document.getElementById("form").addEventListener("submit", function(e){

e.preventDefault(); // stops page reload

console.log("Form handled with JavaScript");

});
Without preventDefault(), the page reloads and JavaScript data may be lost.

5. JavaScript Events

An event is an action that happens in the browser.

Common Form Events

Event Description
click User clicks element
submit Form submitted
input User types in field
change Input value changes
focus Input receives focus
blur Input loses focus

6. Event Bubbling

Event bubbling means the event starts from the target element and moves upward through its ancestors.

Structure


DIV (parent)
   |
BUTTON (child)

Example

Output when clicking button

Button clicked
Div clicked
The event first triggers on the button, then bubbles to the parent.

7. Stopping Event Bubbling

Use stopPropagation() to prevent the event from reaching parent elements. 

document.getElementById("child").addEventListener("click", function(e){

console.log("Button clicked");

e.stopPropagation();

});
Now the parent event will not run.

9. Event Propagation

Event propagation describes how events travel through the DOM.

Three Phases


1️⃣ Capturing Phase
Document → Parent → Child

2️⃣ Target Phase
Event reaches target element

3️⃣ Bubbling Phase
Child → Parent → Document

Capturing Example

element.addEventListener("click", handler, true);
The third parameter true enables capturing.

Bubbling Example

element.addEventListener("click", handler, false);
Default behavior is bubbling.
