JavaScript – Modern Objects

1. Object Destructuring

Object destructuring is a modern JavaScript feature that allows you to extract values from objects and store them in variables easily.

Instead of accessing properties one by one, destructuring allows you to extract them in a single line.

Normal Way

const user = {
name: "Fathima",
age: 22,
city: "Kozhikode"
}

const name = user.name
const age = user.age
const city = user.city

console.log(name)
console.log(age)
console.log(city)

This works, but it becomes repetitive when objects have many properties.

Using Destructuring

const user = {
name: "Fathima",
age: 22,
city: "Kozhikode"
}

const {name, age, city} = user

console.log(name)
console.log(age)
console.log(city)

JavaScript automatically creates variables from object keys.

Important Rule: Variable names must match the object property names.

Renaming Variables

You can rename variables during destructuring. 

const user = {
name: "Fathima",
age: 22
}

const {name: userName, age: userAge} = user

console.log(userName)
console.log(userAge)

Default Values

If a property does not exist, you can give a default value. 

const user = {
name: "Fathima"
}

const {name, age = 18} = user

console.log(age)

Destructuring in Functions

function printUser({name, age}) {
console.log(name)
console.log(age)
}

printUser({
name: "Fathima",
age: 22
})
Destructuring is very common in React when receiving props.

2. Shorthand Properties

When creating objects, JavaScript allows a shorter syntax if the variable name and property name are the same.

Normal Object Creation

const name = "Fathima"
const age = 22

const user = {
name: name,
age: age
}

console.log(user)

Using Shorthand Properties

const name = "Fathima"
const age = 22

const user = {
name,
age
}

console.log(user)

This automatically assigns variable values to properties.

Shorthand properties make object creation cleaner and are widely used in modern JavaScript.

3. Object.keys()

Object.keys() returns an array of all keys in an object. 

const user = {
name: "Fathima",
age: 22,
city: "Malappuram"
}

const keys = Object.keys(user)

console.log(keys)
Output 
["name","age","city"]

Looping Using Object.keys()

const user = {
name: "Fathima",
age: 22,
city: "Malappuram"
}

Object.keys(user).forEach(key => {
console.log(key, user[key])
})

4. Object.values()

Returns an array of object values. 

const user = {
name: "Fathima",
age: 22,
city: "Malappuram"
}

const values = Object.values(user)

console.log(values)
Output 
["Fathima",22,"Malappuram"]

5. Object.entries()

Returns key-value pairs as arrays. 

const user = {
name: "Fathima",
age: 22
}

const entries = Object.entries(user)

console.log(entries)
Output 
[
["name","Fathima"],
["age",22]
]

Looping With entries

const user = {
name: "Fathima",
age: 22
}

for(const [key,value] of Object.entries(user)){
console.log(key,value)
}

6. Shallow Copy vs Deep Copy

Copying objects in JavaScript is tricky because objects are stored by reference.

Shallow Copy

A shallow copy only copies the first level. Nested objects are still shared. 

const user = {
name: "Fathima",
address: {
city: "Kozhikode"
}
}

const copy = {...user}

copy.address.city = "Delhi"

console.log(user.address.city)

Output will also change in original object.

Because nested objects still reference the same memory.

Ways to Create Shallow Copy

Object.assign({}, obj)

{...obj}

7. Deep Copy

Deep copy duplicates the entire object including nested objects.

Changes in copied object will NOT affect original object.

8. structuredClone()

Modern JavaScript introduced structuredClone() to create deep copies. 

const user = {
name: "Fathima",
address:{
city:"Kozhikode"
}
}

const copy = structuredClone(user)

copy.address.city = "Delhi"

console.log(user.address.city)
Output 
Kozhikode

Original object is not affected.

structuredClone() is the safest and modern way to deep copy objects.
