JavaScript Control Flow

Control flow decides which code runs and when based on conditions.

1️⃣ if Statement

The if statement executes a block of code if a condition is true.


let age = 18;

if(age >= 18){
    console.log("You are eligible to vote");
}
Condition inside if must return TRUE or FALSE.

2️⃣ if...else Statement

Used when we want two possible outcomes.


let number = 5;

if(number % 2 === 0){
    console.log("Even number");
}else{
    console.log("Odd number");
}

3️⃣ if...else if...else

Used when we have multiple conditions.


let mark = 85;

if(mark >= 90){
    console.log("Grade A");
}
else if(mark >= 75){
    console.log("Grade B");
}
else if(mark >= 50){
    console.log("Grade C");
}
else{
    console.log("Fail");
}

4️⃣ Nested if

Placing an if statement inside another if statement.


let username = "admin";
let password = "1234";

if(username === "admin"){
    if(password === "1234"){
        console.log("Login successful");
    }else{
        console.log("Wrong password");
    }
}else{
    console.log("Invalid username");
}
Nested if is used when one condition depends on another.

5️⃣ Ternary Operator ( ? : )

Short form of if...else.

Syntax: 

condition ? trueValue : falseValue;
Example: 

let age = 20;

let result = (age >= 18) ? "Adult" : "Minor";
console.log(result);
Use ternary for simple conditions only.

6️⃣ Nested Ternary Operator

A nested ternary means using one ternary operator inside another.

Syntax:


condition1 ? value1 :
condition2 ? value2 :
condition3 ? value3 :
defaultValue;

Example:


let mark = 85;

let grade = mark >= 90 ? "Grade A" :
            mark >= 75 ? "Grade B" :
            mark >= 50 ? "Grade C" :
            "Fail";

console.log(grade);

Output:


Grade B
⚠️ Nested ternary should be used carefully. If the logic becomes complex, prefer if...else if for better readability.

6️⃣ switch Statement

Used when checking multiple values of one variable.


let day = 3;

switch(day){
    case 1:
        console.log("Monday");
        break;
    case 2:
        console.log("Tuesday");
        break;
    case 3:
        console.log("Wednesday");
        break;
    default:
        console.log("Invalid day");
}
Break is important to stop execution.
