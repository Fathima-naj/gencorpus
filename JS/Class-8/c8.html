JavaScript Arrays – Advanced Concepts

1. Stack (LIFO)

A Stack is a data structure that follows the principle LIFO (Last In, First Out). The last element added will be the first element removed.

Example (Stack using Array)

let stack = []; stack.push(10); stack.push(20); stack.push(30); console.log(stack); stack.pop(); console.log(stack);
[10,20,30] [10,20]
push() adds an element to stack. pop() removes the last element.

2. Queue (FIFO)

A Queue is a linear data structure that follows the principle:

👉 FIFO – First In, First Out

This means the first element added to the queue is the first one to be removed.

Example (Queue using Array)

let queue = []; queue.push("A"); queue.push("B"); queue.push("C"); console.log(queue); queue.shift(); console.log(queue);
["A","B","C"] ["B","C"]
shift() removes the first element from array.

3. Higher Order Functions (HOF)

A Higher Order Function (HOF) is a function that either takes another function as an argument or returns a function.

In JavaScript, functions are treated as values. Because of this, we can pass functions inside other functions just like variables. When a function works with another function in this way, it is called a Higher Order Function.

Example:

function greet(name){
    return "Hello " + name;
}

function processUser(callback){
    console.log(callback("Fathima"));
}

processUser(greet);

In the above example, processUser() is the Higher Order Function because it receives another function (greet) as an argument.

Many JavaScript array methods are Higher Order Functions because they accept a function as a parameter to process each element of the array.

Common Array Higher Order Functions:

  • forEach() – Executes a function for each array element
  • map() – Creates a new array by transforming elements
  • filter() – Creates a new array with filtered elements
  • reduce() – Reduces array values into a single value
  • find() – Returns the first matching element
  • some() – Checks if at least one element matches a condition
  • every() – Checks if all elements satisfy a condition

4. forEach()

forEach() executes a function for each array element. It does not return a new array. 

let numbers = [1,2,3,4];

numbers.forEach(function(num){
console.log(num);
});
1 2 3 4

5. map()

map() creates a new array by transforming each element. 

let numbers = [1,2,3,4];

let square = numbers.map(function(n){
return n*n;
});

console.log(square);
[1,4,9,16]

6. filter()

filter() returns elements that satisfy a condition. 

let numbers = [10,15,20,25,30];

let result = numbers.filter(function(n){
return n>20;
});

console.log(result);
[25,30]

7. reduce()

reduce() reduces the array into a single value. Often used for sum or totals. 

let numbers = [1,2,3,4];

let sum = numbers.reduce(function(acc,val){
return acc+val;
},0);

console.log(sum);
10

8. find()

find() returns the first element that matches the condition. 

let numbers = [5,10,15,20];

let result = numbers.find(function(n){
return n>10;
});

console.log(result);
15

9. some()

some() checks if at least one element satisfies the condition. Returns true or false. 

    
let numbers = [1,3,5,8];

let result = numbers.some(function(n){
return n%2===0;
});

console.log(result);
true

10. every()

every() checks if all elements satisfy the condition. 

let numbers = [2,4,6,8];

let result = numbers.every(function(n){
return n%2===0;
});

console.log(result);
true

1. length

length returns the number of elements in an array. 

 let arr = [1,2,3,4];

console.log(arr.length);
4

2. toString()

toString() converts an array into a string. 

 let arr = [1,2,3];

console.log(arr.toString());
"1,2,3"

3. at()

at() returns the element at a specific index. Supports negative index. 

 let arr = [10,20,30];

console.log(arr.at(-1));
30

4. join()

join() combines array elements into a string with a separator. 

 let arr = ["A","B","C"];

console.log(arr.join("-"));
"A-B-C"

5. Array.isArray()

Checks whether a value is an array or not. 

 let arr = [1,2,3];

console.log(Array.isArray(arr));
true

6. concat()

concat() merges two or more arrays. 

 let a = [1,2]; let b = [3,4];

let result = a.concat(b);

console.log(result);
[1,2,3,4]

7. flat()

flat() flattens nested arrays into a single array. 

 let arr = [1,[2,3],[4,5]];

console.log(arr.flat());
[1,2,3,4,5]

8. slice()

slice() returns a portion of an array without modifying the original array. 

 let arr = [1,2,3,4];

console.log(arr.slice(1,3));
[2,3]

9. splice()

splice() adds/removes elements and modifies the original array. 

 let arr = [1,2,3];

arr.splice(1,1,99);

console.log(arr);
[1,99,3]

10. indexOf()

indexOf() returns the first index of an element. 

 let arr = [1,2,3,2];

console.log(arr.indexOf(2));
1

11. lastIndexOf()

lastIndexOf() returns the last index of an element. 

 let arr = [1,2,3,2];

console.log(arr.lastIndexOf(2));
3

12. includes()

includes() checks if an element exists in the array. 

 let arr = [1,2,3];

console.log(arr.includes(2));
true

13. reverse()

reverse() reverses the array (modifies original array). 

 let arr = [1,2,3];

arr.reverse();

console.log(arr);
[3,2,1]

14. sort()

sort() sorts the array elements (by default as strings). 

 let arr = [3,1,2];

arr.sort();

console.log(arr);
[1,2,3]

15. sort() with Numbers

By default, sort() treats numbers as strings. So we use a compare function to sort numbers correctly. 

 let arr = [10, 5, 2, 25];

// Ascending order
arr.sort(function(a, b){
return a - b;
});

console.log(arr);
[2, 5, 10, 25]

16. sort() Descending

To sort numbers in descending order, reverse the subtraction. 

 let arr = [10, 5, 2, 25];

// Descending order
arr.sort(function(a, b){
return b - a;
});

console.log(arr);
[25, 10, 5, 2]

11. Spread Operator (...)

Spread operator expands elements of an array.

allows us to quickly copy all or part of an existing array or object into another array or object.

let a = [1,2,3]; let b = [...a,4,5]; console.log(b);
[1,2,3,4,5]

12. Array Destructuring

Array Destructuring is a JavaScript feature that allows us to extract values from an array and store them in variables easily.

Instead of accessing values using indexes like this: 

let numbers = [10,20,30];

let a = numbers[0];
let b = numbers[1];
let c = numbers[2];

We can use destructuring to make the code shorter and cleaner.

Basic Example

let numbers = [10,20,30];

let [a,b,c] = numbers;

console.log(a);
console.log(b);
console.log(c);
10 20 30

Here:

  • a gets the first value
  • b gets the second value
  • c gets the third value
---

Skipping Values

We can skip values using commas. 

let numbers = [10,20,30,40];

let [first,,third] = numbers;

console.log(first);
console.log(third);
10 30
---

Default Values

If the array does not have enough values, we can assign default values. 

let numbers = [10];

let [a,b=20] = numbers;

console.log(a);
console.log(b);
10 20
---

Using Rest Operator

The rest operator (...) collects remaining values into another array. 

let numbers = [1,2,3,4,5];

let [first,second,...rest] = numbers;

console.log(first);
console.log(second);
console.log(rest);
1 2 [3,4,5]
Array destructuring makes code cleaner and is commonly used in modern JavaScript and frameworks like React.
