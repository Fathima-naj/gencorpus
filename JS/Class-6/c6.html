JavaScript Functions

A function is a reusable block of code designed to perform a task.

1️⃣ Function Declaration & Calling


function greet(){
    console.log("Hello Students");
}

greet();   // Calling the function
Function declaration is hoisted (we will learn hoisting later).

2️⃣ Parameters & Return


function add(a, b){
    return a + b;
}

let result = add(10, 5);
console.log(result);
  • Parameter → Variable inside function (a, b)
  • Argument → Value passed while calling (10, 5)
Return stop the execution of function and return a value

3️⃣ Function Expression 


const multiply = function(a, b){
    return a * b;
};

console.log(multiply(4, 5));
Function expression is NOT hoisted like normal function.

4️⃣ Arrow Functions


const subtract = (a, b) => {
    return a - b;
};

console.log(subtract(10, 3));

Short Version:


const square = num => num * num;

console.log(square(5));
If only one line, return keyword is not required.

5️⃣ Default Parameters 


function greetUser(name = "Guest"){
    console.log("Welcome " + name);
}

greetUser("Fathima");
greetUser();
If argument is missing, default value is used.

6️⃣ Hoisting

During the memory creation phase of the execution context, JavaScript allocates memory for variables and functions before executing the code line by line.

Function Hoisting


greet();

function greet(){
    console.log("Hello");
}
Function declaration works before definition because it is hoisted.

Variable Hoisting (var)


console.log(a);
var a = 10;
Output: undefined
var is hoisted but initialized with undefined.

let & const


console.log(b);
let b = 20;
Output: ReferenceError

7️⃣ Temporal Dead Zone (TDZ)

Temporal Dead Zone is the time between variable hoisting and initialization for let and const. 


{
    console.log(x); // Error
    let x = 5;
}
Between block start and variable initialization → variable is in TDZ.

Simple Rule:

  • var → undefined
  • let/const → ReferenceError (TDZ)
