JavaScript DOM Basics

DOM stands for Document Object Model. It is a programming interface that represents the structure of an HTML document as a tree of objects.

Using DOM, JavaScript can access and manipulate HTML elements such as text, attributes, styles, and events.

1. What is DOM?

When a webpage loads, the browser converts HTML into a tree-like structure called the DOM. Each HTML element becomes a node that JavaScript can access. 

HTML Structure

<body>
  <h1>Hello</h1>
</body>

DOM Tree

document
 └── body
      └── h1
Example: 
// prints the entire HTML document
console.log(document);

2. Selecting Elements

To manipulate elements, JavaScript must first select them from the DOM.

getElementById()

Selects an element using its unique ID.

const title = document.getElementById("title");
Example HTML: 
<h1 id="title">Hello</h1>
---

getElementsByClassName()

Selects all elements that have the same class name.

const items = document.getElementsByClassName("item");
Example: 
<p class="item">One</p>
<p class="item">Two</p>
---

getElementsByTagName()

Selects elements by their HTML tag name.

const paragraphs = document.getElementsByTagName("p");
---

querySelector()

Selects the first element that matches a CSS selector. 

const element = document.querySelector(".box");
Example: 
<div class="box">Content</div>
---

querySelectorAll()

Selects all elements that match a CSS selector. 

const elements = document.querySelectorAll(".box");
querySelector and querySelectorAll use CSS selector syntax.

3. Updating Text

JavaScript can modify the content of HTML elements.

innerText

Changes visible text inside an element.

document.getElementById("title").innerText = "New Heading";
---

textContent

Changes text content including hidden text.

document.getElementById("title").textContent = "Updated Text";
---

innerHTML

Allows inserting HTML inside an element.

document.getElementById("box").innerHTML = "<b>Hello</b>";

4. Updating Styles

JavaScript can dynamically change CSS styles. 

const box = document.getElementById("box");

box.style.color = "white";
box.style.backgroundColor = "blue";
box.style.padding = "20px";
Example result: - Text becomes white - Background becomes blue - Padding increases

5. Event Listeners

Events allow JavaScript to respond to user interactions such as clicks, typing, or mouse movement.

Example: 
const btn = document.getElementById("btn");

btn.addEventListener("click", function(){
alert("Button Clicked");
});
Explanation: - `addEventListener()` attaches an event to an element - `"click"` is the event type - function runs when event occurs

6. Common Events

Event Description
click Occurs when user clicks an element
mouseover Occurs when mouse enters element
mouseout Occurs when mouse leaves element
keydown Occurs when keyboard key is pressed
submit Occurs when form is submitted
