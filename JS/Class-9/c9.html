Objects

Objects are used to store multiple values in a single variable using key–value pairs. 

let person = {
 name: "Fathima",
 age: 22,
 city: "Malappuram"
};
  • name, age, city → properties (keys)
  • "Fathima", 22 → values

5. Object Methods

Functions inside objects are called methods.

let person = {
 name: "Nisha",
 greet: function(){
  console.log("Hello!");
 }
};

person.greet();

Using this keyword

let user = {
 name: "Arjun",

 sayHello: function(){
  console.log("Hello " + this.name);
 }
};

user.sayHello();

Difference Between Function and Object Method

A function is a block of reusable code that performs a task. When a function is placed inside an object, it is called a method.

1. Function

A function exists independently and is not part of any object. 

function greet(){
 console.log("Hello");
}

greet();

Here greet() is a normal function.

2. Object Method

When a function is stored inside an object property, it is called a method. 

let person = {

 name: "Aisha",

 greet: function(){
  console.log("Hello");
 }

};

person.greet();

Here greet() belongs to the person object, so it is called a method.

3. Method Using this

Methods often use this to access object properties. 

let user = {

 name: "Rahul",

 sayHello: function(){
  console.log("Hello " + this.name);
 }

};

user.sayHello();

Function Method

6. The this Keyword

In JavaScript, this refers to the object that is currently executing the function. It is not fixed — its value depends on how the function is called.

Instead of writing the object name again, we use this.

Example

let user = {
 name: "Rahul",
 age: 25,

 sayHello: function(){
  console.log("Hello " + this.name);
 }
};

user.sayHello();

Output

Hello Rahul

Here:

  • this.name refers to user.name
  • The method sayHello() is called by the user object
  • So this represents the user object
---

Without using this

let user = {
 name: "Rahul",

 sayHello: function(){
  console.log("Hello " + user.name);
 }
};

This works, but using this is better because it makes the method reusable.

---

Important Points About this

  • 1. Depends on how function is called
    this value changes based on the calling context, not where it is written.

  • 2. Global Scope 
    console.log(this);
    In browser → refers to window object

  • 3. Inside a Normal Function 
    function show(){
 console.log(this);
}
show();
    Non-strict mode → window
    Strict mode → undefined

  • 4. Arrow Functions 
    let user = {
 name: "Rahul",
 greet: () => {
  console.log(this.name);
 }
};
user.greet();
    Arrow functions do not have their own this.
    They take this from the surrounding (lexical) scope.
