JavaScript Operators

1️⃣ Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Operator Description Example
+ Addition 10 + 5 = 15
- Subtraction 10 - 5 = 5
* Multiplication 10 * 5 = 50
/ Division 10 / 5 = 2
% Modulus (Remainder) 10 % 3 = 1
Example: 

let a = 10;
let b = 5;

console.log(a + b); // 15
console.log(a - b); // 5
console.log(a * b); // 50
console.log(a / b); // 2
console.log(a % b); // 0

2️⃣ Assignment Operators

Assignment operators are used to assign values to variables.

Operator Example Meaning
= x = 5 Assign value 5 to x
+= x += 2 x = x + 2
-= x -= 2 x = x - 2
*= x *= 2 x = x * 2
/= x /= 2 x = x / 2
%= x %= 2 x = x % 2 

let x = 10;
x += 5;   // x = 15
x -= 3;   // x = 12

console.log(x);

3️⃣ Increment and Decrement

Increment (++) increases value by 1.

Decrement (--) decreases value by 1.

Post Increment

It returns the value before the increment.


let a = 5;
console.log(a++); // 5 (first prints, then increases)
console.log(a);   // 6

Pre Increment

It returns the value after the increment.


let b = 5;
console.log(++b); // 6 (first increases, then prints)

Decrement


let c = 5;
console.log(c--); // 5
console.log(c);   // 4

4️⃣ Comparison Operators (== vs ===)

Comparison operators compare two values and return true or false.

Operator Description
== Equal to (checks value only)
=== Strict Equal (checks value and type)
!= Not equal
> Greater than
< Less than
>= Greater or Equal
<= Less or Equal 

let a = 5;
let b = "5";

console.log(a == b);  // true (value same)
console.log(a === b); // false (different data type)

Important: Always prefer === in real projects.

5️⃣ Logical Operators

Logical operators are used to combine multiple conditions.

Operator Name Example
&& AND true && true → true
|| OR true || false → true
! NOT !true → false 

let age = 20;
let hasID = true;

console.log(age > 18 && hasID); // true
console.log(age < 18 || hasID); // true
console.log(!hasID);            // false
