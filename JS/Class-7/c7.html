JavaScript Core Concepts

Scope in JavaScript

Scope defines where a variable can be accessed in a program. It controls the visibility and lifetime of variables.

In JavaScript, there are mainly three types of scope:

  • Global Scope – Variable accessible everywhere.
  • Function Scope – Variable accessible only inside a function.
  • Block Scope – Variable accessible only inside { } block.

1. Block Scope vs Function Scope

Function Scope (var)

Function scope means a variable declared inside a function can only be used inside that function. 

function test() {
    var a = 10;
}
console.log(a); // Error

Block Scope (let)

Block scope means a variable declared inside a block { } can only be used inside that block. 

if(true){
    let b = 20;
}
console.log(b); // Error

2. var vs let

Both var and let are used to declare variables, but they behave differently.

  • var → Function scoped
  • let → Block scoped
  • var allows redeclaration
  • let does not allow redeclaration in same scope
  • let is safer and recommended in modern JavaScript
var x = 10;
var x = 20; // Allowed

let y = 10;
let y = 20; // Error

3. Lexical Scope & Closures

Lexical scope means a function can access variables from its parent (outer) function.

Lexical Scope Example

function outer(){
    let name = "JS";

    function inner(){
        console.log(name);
    }
    inner();
}
outer();

A closure is created when an inner function remembers and accesses variables from its outer function even after the outer function has finished execution.

Closure Example

function counter(){
    let count = 0;

    return function(){
        count++;
        console.log(count);
    }
}

let c = counter();
c();
c();

4. Array Creation & Access

An array is a data structure used to store multiple values in a single variable.

Arrays are zero-indexed, meaning the first element starts at index 0. 

let arr = [10, 20, 30];

console.log(arr[0]);      // 10
console.log(arr.length);  // 3

5. Looping in JavaScript

Looping is used to execute a block of code multiple times. It is commonly used for arrays, numbers, and repetitive tasks.

1. for Loop

Used when you know how many times you want to run the loop. 

for(let i = 0; i < 5; i++){
    console.log(i);
}

2. while Loop

Runs as long as the condition is true. 

let i = 0;

while(i < 5){
    console.log(i);
    i++;
}

3. do...while Loop

Executes at least once, even if condition is false. 

let i = 0;

do{
    console.log(i);
    i++;
}while(i < 5);

4. for...of Loop (Best for Arrays)

Used to loop through array values directly. 

let arr = [10,20,30];

for(let value of arr){
    console.log(value);
}

5. for...in Loop

Used to loop through indexes of an array or keys of an object. 

let arr = [10,20,30];

for(let index in arr){
    console.log(index);      // prints index
    console.log(arr[index]); // prints value
}

6. break Statement

Stops the loop immediately. 

for(let i = 0; i < 10; i++){
    if(i === 5){
        break;
    }
    console.log(i);
}

7. continue Statement

Skips current iteration and continues with next. 

for(let i = 0; i < 5; i++){
    if(i === 2){
        continue;
    }
    console.log(i);
}

8. Nested Loop

A loop inside another loop. Commonly used for patterns and matrix problems. 

for(let i = 1; i <= 3; i++){
    for(let j = 1; j <= 3; j++){
        console.log(i, j);
    }
}

When to Use Which Loop?

  • for → When count is known
  • while → When condition-based looping
  • do...while → Must execute at least once
  • for...of → Best for arrays
  • for...in → Best for objects

6. Array Methods

JavaScript provides built-in methods to add or remove elements from an array. 

let numbers = [1,2,3];

numbers.push(4);     
numbers.pop();       
numbers.shift();     
numbers.unshift(0);  

console.log(numbers);
  • push() → Adds element at the end
  • pop() → Removes element from the end
  • shift() → Removes first element
  • unshift() → Adds element at the beginning
