JavaScript Day 3 – Data Types

A data type defines the type of value stored in a variable. JavaScript is a dynamically typed language, meaning the data type is determined automatically. 

let name = "Fathima";
let age = 22;
let isStudent = true;

1. Primitive Data Types

Primitive data types store a single value.

  • String
  • Number
  • Boolean
  • Undefined
  • Null
  • BigInt
  • Symbol

2. typeof Operator

The typeof operator is used to check the type of a variable. 

let name = "Ali";
let age = 25;
let isAdmin = false;

console.log(typeof name);
console.log(typeof age);
console.log(typeof isAdmin);
Output 
string
number
boolean
More examples: 
console.log(typeof undefined);
console.log(typeof null);
Output 
undefined
object

Note: null returning object is a known JavaScript bug.

3. String

Strings represent text values. 

let firstName = "Sara";
let lastName = 'Khan';
Strings can include letters, numbers, and symbols. 
let message = "Welcome to JavaScript";

4. Number

Numbers represent numeric values. 
let age = 20;
let price = 199.99;
JavaScript numbers include both integers and decimals.

Special Number Values

NaN (Not a Number)

console.log("hello" * 5);
Output 
NaN

Infinity

console.log(10 / 0);
Output 
Infinity

5. Boolean

Boolean values represent logical values. 
let isLoggedIn = true;
let isAdmin = false;
Booleans are commonly used in conditions.

6. Undefined

A variable declared without a value becomes undefined. 
let score;

console.log(score);
Output 
undefined

7. Null

Null represents an intentional empty value. 
let result = null;

console.log(result);
Output 
null

8. null vs undefined

undefined null
Variable declared but not assigned Intentional empty value
Automatically assigned Assigned manually
typeof → undefined typeof → object
Example 
let x;
console.log(x);

let y = null;
console.log(y);

9. String Concatenation

String concatenation means joining strings together. 
let firstName = "Ali";
let lastName = "Khan";

let fullName = firstName + " " + lastName;

console.log(fullName);
Output 
Ali Khan

10. Template Literals

Template literals use backticks (`). They allow variables inside strings using ${}. 
let name = "Sara";
let age = 24;

let message = `My name is ${name} and I am ${age} years old`;

console.log(message);
Output 
My name is Sara and I am 24 years old
Advantages:
  • Easier to read
  • Supports multi-line strings
  • Supports variable interpolation

11. Type Coercion

Type coercion means automatic conversion of data types. Example: 
console.log("5" + 2);
Output 
52
Explanation Number 2 becomes a string.
Example 
console.log("5" - 2);
Output 
3
Explanation String "5" becomes number 5.
Example 
console.log(true + 1);
Output 
2
true becomes 1.

12. Truthy and Falsy Values

In JavaScript, some values behave like true or false. Falsy values:
  • false
  • 0
  • "" (empty string)
  • null
  • undefined
  • NaN
Example 
if(0){
 console.log("True");
}else{
 console.log("False");
}
Output 
False

13. Explicit Type Conversion

Sometimes we convert types manually.

Convert to Number

let num = Number("100");
console.log(num);

Convert to String

let str = String(200);
console.log(str);

Convert to Boolean

let value = Boolean(1);
console.log(value);

2. Non-Primitive Data Types

Non-primitive data types are used to store multiple values or more complex data. They are also called reference types.

  • Object
  • Array
  • Function

Object

Objects store data in key-value pairs.

let user = {
  name: "Fathima",
  age: 22
};

console.log(user.name);

Array

Arrays store multiple values in a list.

let fruits = ["apple", "banana", "mango"];

console.log(fruits[0]);

Function

Functions are reusable blocks of code.

function greet(){
  console.log("Hello!");
}

greet();

Note: Non-primitive types are stored by reference, not by value.
