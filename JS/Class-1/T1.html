JavaScript – Day 1

1. What is JavaScript?

JavaScript is a high-level programming language used to make websites interactive and dynamic. Without JavaScript, websites would only display static content.

Technologies of the Web

  • HTML – Defines structure (heading, paragraph, button)
  • CSS – Adds styling (colors, layout, spacing)
  • JavaScript – Adds logic (clicks, actions, updates)

Example

<script> document.write("Hello JavaScript"); </script>
Hello JavaScript
JavaScript can update content, respond to user actions, validate forms, and communicate with servers without reloading the page.

2. How JavaScript Works

Single Threaded

JavaScript executes one task at a time.

Synchronous Execution

Code runs line by line from top to bottom.


console.log("Start");
console.log("Middle");
console.log("End");
Start
Middle
End

Execution Context

Whenever JavaScript runs, it creates a special environment called an Execution Context where all code is executed.

This context manages:

  • Variables (let, const, var)
  • Functions
  • The value of this

Two Phases of Execution

JavaScript does not execute code immediately. It works in two phases:

1. Memory Creation Phase (Creation Phase)

  • Variables are stored with initial value undefined
  • Functions are stored completely in memory

2. Code Execution Phase

  • Code runs line by line
  • Values are assigned to variables
  • Functions are executed

Example


console.log(a);

var a = 10;

console.log(a);
undefined
10
During memory phase, variable a is created with value undefined. Later in execution phase, it gets the value 10.

3. Add JavaScript in HTML

JavaScript is added using the <script> tag.

Internal JavaScript

<script> console.log("Hello"); </script>

External JavaScript

<script src="script.js"></script>

Placement

  • Inside <head>
  • At the end of <body> (recommended)
Placing script at the bottom improves page loading performance.

4. Role of JavaScript

JavaScript controls the behavior of web applications.

  • Update content dynamically
  • Handle button clicks
  • Validate user input
  • Fetch data from APIs

Example


let name = "Fathima";
document.write("Welcome " + name);
Welcome Fathima
JavaScript enables dynamic UI without refreshing the page.

5. Browser vs Node.js

JavaScript runs in different environments.

Feature Browser Node.js
DOM Access Yes No
File System No Yes
Usage Frontend Backend

Example

document.write("Hello"); // ❌ Works only in browser
console.log("Hello");    // ✅ Works everywhere
Node.js allows JavaScript to run outside the browser.

7. V8 Engine

JavaScript cannot be understood directly by the computer. It needs an engine to convert it into machine code.

JavaScript → V8 Engine → Machine Code → Output
  • Used in Google Chrome
  • Used in Node.js
V8 engine converts JavaScript into fast machine-level instructions.

8.Where JavaScript runs

  • Web Browsers (Chrome, Firefox)
  • Servers using Node.js
  • Mobile Apps (React Native)
  • Desktop Apps (Electron)

11. First Program

Create a file hello.js

console.log("Hello JavaScript");

Run in terminal:

node hello.js
Hello JavaScript
Node executes JavaScript files outside the browser.

12. console.log()

console.log() prints output to the console.

console.log("Hello");
console.log("Age:", 20);
console.log(10 + 20);

Why use it?

  • Debug code
  • Check values
  • Track program flow
Developers use console.log extensively for debugging.

13. Types of Output

alert("Hello");        // Popup (Browser only)
document.write("Hi");  // Writes on webpage
console.log("Hey");    // Prints in console
alert() is rarely used in modern apps, mostly for learning.
