Variables & Syntax

Variables are used to store data values. In JavaScript, variables can store numbers, text, arrays, objects, and more. 

let name = "Fathima";
let age = 22;

Here:

  • name and age are variables
  • "Fathima" and 22 are values

1. Variable Concept

A variable is a container used to store data values. 

let city = "Kochi";

Here:

  • city → variable name (identifier)
  • "Kochi" → value stored in memory

How JavaScript Stores Variables

When JavaScript executes this code, it:

  • Creates a memory space
  • Stores the value
  • Links the variable name to that value
Think of a variable as a name tag attached to a box storing data.

Example

let score = 50;

score = 80;

console.log(score);
Output: 
80

The variable updates its value instead of creating a new one.

2. Declaring Variables

Declaring a variable means telling JavaScript to create it.

JavaScript has three keywords:

  • var → old method
  • let → modern and recommended
  • const → constant values
In modern JavaScript:
  • Use let for changing values
  • Use const by default
  • Avoid var

3. var

Features

  • Can be reassigned
  • Can be redeclared

Example

var age = 20;
age = 25;
console.log(age);

Redeclaration

var name = "Ali";
var name = "Rahul";

console.log(name);

4. let

let is the modern way to declare variables. 

let age = 25;

The value can be updated. 

let score = 80;

score = 90;

console.log(score);

But let cannot be redeclared in the same scope. 

let name = "Sara";
let name = "Aisha";

This will cause an error.

5. const

const is used when the value should not change. 

const country = "India";

Reassigning a const variable causes an error. 

const pi = 3.14;

pi = 3.1415;

This will give an error.

Create a constant variable called PI and print its value.

6. Difference Between var, let, const

Feature var let const
Redeclaration Allowed Not allowed Not allowed
Reassignment Allowed Allowed Not allowed
Modern usage Rare Common Common

7. Identifier Naming Rules

Variable names are called identifiers.

Rules:
  • Names must start with a letter, $, or _
  • Names cannot start with a number
  • No spaces allowed
  • JavaScript keywords cannot be used
  • Names are case sensitive

Valid Names

let userName;
let _price;
let $amount;

Invalid Names

let 1name;
let user name;
let let;

8. Comments

Comments are used to explain code and are ignored by JavaScript.

Single Line Comment

// This is a comment
let x = 10;

Multi Line Comment

/*

9. Printing Multiple Values

We can print multiple values using console.log(). 

let name = "Rahul";
let age = 25;

console.log(name, age);
Output 
Rahul 25

Using String Concatenation

console.log("Name: " + name + " Age: " + age);
Output 
Name: Rahul Age: 25

Template Literals (Modern Way)

console.log(`Name: ${name}, Age: ${age}`);
Use template literals instead of + for cleaner code.

10. typeof Operator

The typeof operator is used to check the data type of a value. 

let name = "Fathima";
let age = 22;
let isStudent = true;

console.log(typeof name);
console.log(typeof age);
console.log(typeof isStudent);
Output 
string
number
boolean

More Examples

console.log(typeof 100);
console.log(typeof "Hello");
console.log(typeof false);
console.log(typeof undefined);
