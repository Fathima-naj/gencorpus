3. Position Utilities

Bootstrap provides position utility classes to control how elements are positioned on the page.

Position Types
  • position-static – Default positioning. The element follows the normal document flow. Top, left, right and bottom properties will not affect it.
  • position-relative – The element remains in the normal flow, but it can be moved relative to its original position using top, bottom, left, or right.
  • position-absolute – The element is positioned relative to its nearest positioned parent (relative, absolute, fixed, or sticky). It is removed from the normal document flow.
  • position-fixed – The element is positioned relative to the browser window. It stays fixed in the same position even when the page is scrolled.
  • position-sticky – The element behaves like relative until a scroll position is reached, then it behaves like fixed.

3. Spacing Utilities

Bootstrap spacing utilities control margin (m) and padding (p).

Spacing Syntax
m - sets margin
p - sets padding

Where sides is one of:

t - sets margin-top or padding-top
b - sets margin-bottom or padding-bottom
s - sets margin-left or padding-left
e - sets margin-right or padding-right
x - sets left and right
y - sets top and bottom
blank - sets spacing on all 4 sides

Where size ranges from 1 to 5:

0 - sets margin or padding to 0
1 - sets margin or padding to .25rem
2 - sets margin or padding to .5rem
3 - sets margin or padding to 1rem
4 - sets margin or padding to 1.5rem
5 - sets margin or padding to 3rem

Note:
The spacing scale in Bootstrap ranges from 1 to 5. 
Margin also supports an additional value:

auto - sets margin to auto
Examples
<div class="p-4 bg-secondary text-white">Padding 4</div>

<div class="mt-5 bg-dark text-white p-3">Margin Top 5</div>

<div class="mx-auto bg-primary text-white p-3">Horizontal Auto Margin</div>
Padding 4
Margin Top 5
