Bootstrap Forms

1️⃣ Form Layout (form-control)

form-control is used to style input fields in Bootstrap.

  • Makes input full width
  • Adds padding and border
  • Makes the form responsive
  • Gives professional styling

2️⃣ Checkboxes, Radios & Switches

form-check is used for checkboxes, radio buttons and switches.

  • Checkbox → Multiple options can be selected
  • Radio → Only one option can be selected (same name attribute)
  • Switch → Toggle style checkbox

3️⃣ Input Groups (Addons)

input-group is used to add icons, symbols, or text before or after input fields.

  • Useful for currency, username, URL, etc.
  • Uses input-group-text for addons

4️⃣ Floating Labels

form-floating creates floating label inputs.

  • Label appears inside input field
  • Moves above when user types
  • Modern UI design

5️⃣ Validation Classes

Bootstrap provides validation classes to show input status.

  • is-valid → Green border (correct input)
  • is-invalid → Red border (wrong input)
  • valid-feedback → Success message
  • invalid-feedback → Error message
