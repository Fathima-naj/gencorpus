Bootstrap Components

1. Buttons & Button Groups

Definition: Buttons are styled using .btn class.

Example Code:

<button class="btn btn-primary">Primary</button>
<button class="btn btn-success">Success</button>
<button class="btn btn-danger">Danger</button>
Output:
Outline Buttons :

  <button class="btn btn-outline-primary">Outline</button>
Button Sizes :

<button class="btn btn-primary btn-lg">Large</button>
<button class="btn btn-primary btn-sm">Small</button>
Button Group Code:

Used to group multiple buttons together.


<div class="btn-group">
  <button class="btn btn-primary">Left</button>
  <button class="btn btn-primary">Middle</button>
  <button class="btn btn-primary">Right</button>
</div>
Output:
Vertical Button Group :

  <div class="btn-group-vertical">
  <button class="btn btn-success">Top</button>
  <button class="btn btn-success">Middle</button>
  <button class="btn btn-success">Bottom</button>
  </div>

2. Alerts

Alerts are used to display important messages.

Example Code:

<div class="alert alert-success">
  Success Message!
</div>

<div class="alert alert-danger">
  Error Message!
</div>
Output:
Success Message!
Error Message!

3. Badges

Badges are used for counters and labels.

Example Code:

<h4>Notifications 
  <span class="badge bg-danger">5</span>
</h4>
Output:

Notifications 5

Pill Badges

  <span class="badge rounded-pill bg-success">New</span>
New

4. Cards

Cards are flexible content containers.

Example Code:

<div class="card" style="width:18rem;">
  <div class="card-body">
    <h5 class="card-title">Card Title</h5>
    <p class="card-text">Card content here.</p>
    <a href="#" class="btn btn-primary">Button</a>
  </div>
</div>
Output:
Card Title

Card content here.

Button
Card with header & footer

<div class="card">
  <div class="card-header">Header</div>
  <div class="card-body">
    <h5 class="card-title">Card Title</h5>
    <p class="card-text">Card content.</p>
  </div>
  <div class="card-footer text-muted">Footer</div>
</div>
Header
Card Title

Card content.

Footer

5. Images & Responsive Images

Example Code:

<img src="image.jpg" class="img-fluid">

6. Navbar

Navbar supports expand, collapse and responsiveness.

Example Code:

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">MySite</a>
  </div>
</nav>
Output:
MySite

7. Breadcrumb

Breadcrumb shows navigation path.

Example Code:

<nav>
  <ol class="breadcrumb">
    <li class="breadcrumb-item">Home</li>
    <li class="breadcrumb-item active">Library</li>
  </ol>
</nav>
Output:
  1. Home
  2. Library
