1. What is Bootstrap?

Bootstrap is a free CSS framework used to create responsive and mobile-first websites quickly.

Why Use Bootstrap?
  • Faster development
  • Mobile-first design
  • Prebuilt components
  • Consistent layout system
Bootstrap CDN Link
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">

2. CDN vs Local Installation

CDN Method

Loads Bootstrap from internet.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet"> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"> </script>
Local Method

Download Bootstrap files and link manually.

<link rel="stylesheet" href="css/bootstrap.min.css"> <script src="js/bootstrap.bundle.min.js"></script>

3. Containers

Bootstrap requires a container to wrap content.

.container

Responsive fixed-width container.

<div class="container">Content</div>
This is inside .container

Width changes based on screen size.

.container-fluid

Full-width container (100%).

<div class="container-fluid">Content</div>
This is inside .container-fluid
Responsive Containers
.container-sm .container-md .container-lg .container-xl .container-xxl
