Tailwind CSS - Layout, Flex & Grid

1. Display Utilities

Display utilities control how elements appear in the layout. They determine whether an element behaves like a block element, inline element, flex container, grid container, or if it is hidden.

Common Display Classes


block
inline
inline-block
hidden
flex
grid

Example


<div class="block bg-gray-200 p-4">Block Element</div>

<span class="inline bg-blue-200">Inline Element</span>
The hidden class is commonly used to hide elements and show them later using responsive prefixes.

2. Flexbox Utilities

Flexbox is a layout system used to arrange elements in a row or column. It helps developers easily align, space, and distribute items inside a container. Flexbox is widely used for:

  • Navigation bars
  • Card layouts
  • Centering elements
  • Responsive layouts
  • Vertical and horizontal alignment

In Tailwind CSS, Flexbox utilities allow you to control layout behavior without writing custom CSS.

1. Enable Flexbox

To use Flexbox, apply the flex class to a container. This turns the element into a flex container. 


flex
Example: 

<div class="flex">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
---

2. Flex Direction

Flex direction controls how items are arranged inside the flex container.

Class Purpose
flex-row Items arranged horizontally (default)
flex-row-reverse Items arranged horizontally in reverse order
flex-col Items arranged vertically
flex-col-reverse Items arranged vertically in reverse order
Example: 

<div class="flex flex-col">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
---

3. Justify Content (Horizontal Alignment)

Controls how items are aligned horizontally along the main axis.

Class Purpose
justify-start Items aligned to the left
justify-center Items centered horizontally
justify-end Items aligned to the right
justify-between Space between items
justify-around Equal space around items
justify-evenly Equal spacing between all items
Example: 

<div class="flex justify-between bg-gray-200 p-4">
  <div>Logo</div>
  <div>Menu</div>
  <div>Profile</div>
</div>
---

4. Align Items (Vertical Alignment)

Controls vertical alignment of items in the container.

Class Purpose
items-start Align items at the top
items-center Align items vertically in the center
items-end Align items at the bottom
items-baseline Align items based on text baseline
items-stretch Stretch items to fill container height
Example: 

<div class="flex items-center h-40 bg-gray-200">
  <div>Aligned Center</div>
</div>
---

5. Flex Wrap

Flex wrap allows items to move to the next line if there is not enough space.

Class Purpose
flex-wrap Allow items to wrap
flex-nowrap Prevent wrapping
flex-wrap-reverse Wrap items in reverse order
Example: 

<div class="flex flex-wrap gap-4">
  <div class="bg-blue-200 p-4">Item</div>
  <div class="bg-blue-200 p-4">Item</div>
  <div class="bg-blue-200 p-4">Item</div>
</div>
---

6. Gap Utilities

Gap utilities create spacing between flex items.

Class Purpose
gap-2 Small gap
gap-4 Medium gap
gap-6 Larger gap
Example: 

<div class="flex gap-4">
  <div class="bg-green-200 p-4">1</div>
  <div class="bg-green-200 p-4">2</div>
  <div class="bg-green-200 p-4">3</div>
</div>
---

7. Flex Grow

Controls how much a flex item grows relative to other items.

Class Purpose
grow Item grows to fill space
grow-0 Item does not grow
Example: 

<div class="flex">
  <div class="grow bg-red-200">Flexible</div>
  <div class="bg-blue-200">Fixed</div>
</div>
---

8. Flex Shrink

Controls how items shrink when space is limited.

Class Purpose
shrink Item can shrink
shrink-0 Item will not shrink
---

9. Order

Order utilities change the visual order of flex items.

Class Purpose
order-1 Move item position
order-2 Second position
order-last Move item to the end
Example: 

<div class="flex">
  <div class="order-2">Second</div>
  <div class="order-1">First</div>
</div>
---

Example: Complete Flex Layout


<div class="flex justify-between items-center bg-gray-200 p-4">

  <div class="font-bold">Logo</div>

  <div class="flex gap-6">
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
  </div>

</div>

This layout is commonly used for navigation bars.

3. Gap Utilities

Gap utilities control the spacing between flex or grid items. Instead of adding margin to each item, Tailwind provides a simpler way to add consistent spacing between elements.

Examples


gap-2
gap-4
gap-6
gap-8
Example: 

<div class="flex gap-4">

<div class="bg-blue-300 p-4">1</div>
<div class="bg-blue-300 p-4">2</div>

</div>

4. Grid System

CSS Grid is a powerful layout system used to create complex layouts. It is commonly used for dashboards, galleries, product grids, and responsive layouts.

Enable Grid


grid
Example: 

<div class="grid">
  <div>Item 1</div>
  <div>Item 2</div>
</div>

5. Grid Template Columns

Grid columns define how many columns exist inside the grid container. 


grid-cols-1
grid-cols-2
grid-cols-3
grid-cols-4
Example: 

<div class="grid grid-cols-3 gap-4">

<div class="bg-green-300 p-4">1</div>
<div class="bg-green-300 p-4">2</div>
<div class="bg-green-300 p-4">3</div>

</div>

6. Grid Template Rows

Grid rows control how many rows exist in the grid layout. 


grid-rows-2
grid-rows-3
grid-rows-4
Example: 

<div class="grid grid-rows-2 gap-4">

<div class="bg-yellow-300 p-4">Row 1</div>
<div class="bg-yellow-300 p-4">Row 2</div>

</div>

7. Responsive Grid Layout

Tailwind allows grid layouts to change based on screen size using responsive prefixes.

Example: 

<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4">

<div class="bg-purple-300 p-4">1</div>
<div class="bg-purple-300 p-4">2</div>
<div class="bg-purple-300 p-4">3</div>
<div class="bg-purple-300 p-4">4</div>

</div>
Explanation:
  • Mobile → 1 column
  • Tablet → 2 columns
  • Laptop → 4 columns

8. Position Utilities

Position utilities control how elements are placed on the page. They determine how an element behaves relative to its normal position or relative to other elements. These utilities work together with directional properties like: top, right, bottom, and left.

Position Classes


static
relative
absolute
fixed
sticky

1. static

static is the default positioning for all HTML elements. Elements follow the normal document flow and cannot be moved using top, left, right, or bottom.

In most cases, you do not need to use static because it is already the default behavior.

Example: 

<div class="static bg-gray-200 p-4">
Normal static element
</div>

2. relative

relative positions the element relative to its normal position. This means the element remains in the document flow, but you can shift it using top, bottom, left, or right.

It is also commonly used to create a reference point for absolutely positioned child elements.

Example: 

<div class="relative top-4 left-4 bg-green-200 p-4">
Moved slightly from original position
</div>
Explanation:
  • The element still occupies its original space.
  • It only moves visually.

3. absolute

absolute removes the element from the normal document flow. The element is positioned relative to the nearest parent element that has relative, absolute, or fixed positioning.

If no positioned parent exists, the element is positioned relative to the entire page.

Example: 

<div class="relative bg-gray-200 p-10">

<div class="absolute top-0 right-0 bg-blue-400 p-2">
Top Right
</div>

</div>
Explanation:
  • The parent container is relative.
  • The child element is positioned at the top-right corner.
  • The element does not take up space in the layout.

4. fixed

fixed positions an element relative to the browser viewport instead of a parent container.

The element stays in the same place even when the page is scrolled.

Common uses:
  • Navigation bars
  • Floating buttons
  • Chat widgets
Example: 

<div class="fixed bottom-4 right-4 bg-blue-500 text-white p-3">
Chat
</div>
Explanation:
  • The element stays at the bottom-right of the screen.
  • Scrolling the page will not move it.

5. sticky

sticky behaves like relative until a scroll position is reached. After that point, it behaves like fixed.

This is commonly used for headers that stay visible while scrolling.

Example: 

<div class="sticky top-0 bg-gray-800 text-white p-4">
Sticky Header
</div>
Explanation:
  • The element scrolls normally at first.
  • When it reaches the top of the screen, it sticks there.

Directional Position Utilities

These classes control the exact position of an element.

Class Meaning
top-0 Position element at top
bottom-0 Position element at bottom
left-0 Position element at left
right-0 Position element at right
top-4 Move element down slightly
left-4 Move element slightly to the right
Example: 

<div class="relative h-40 bg-gray-200">

<div class="absolute bottom-0 left-0 bg-red-400 p-2">
Bottom Left
</div>

</div>
Absolute elements are positioned relative to the nearest parent that has relative, absolute, or fixed positioning. If no such parent exists, the element will be positioned relative to the page.

Practice Tasks

Task 1 – Answer

Create a flex container with 3 boxes aligned in the center.


<div class="flex justify-center items-center h-40 bg-gray-200 gap-4">

  <div class="bg-green-300 p-6">1</div>
  <div class="bg-green-300 p-6">2</div>
  <div class="bg-green-300 p-6">3</div>

</div>

justify-center centers items horizontally and items-center centers items vertically.

Task 2 – Answer

Create a grid layout with 3 columns and spacing between items.


<div class="grid grid-cols-3 gap-4 bg-gray-200 p-4">

  <div class="bg-blue-300 p-6">1</div>
  <div class="bg-blue-300 p-6">2</div>
  <div class="bg-blue-300 p-6">3</div>
  <div class="bg-blue-300 p-6">4</div>
  <div class="bg-blue-300 p-6">5</div>
  <div class="bg-blue-300 p-6">6</div>

</div>

grid enables grid layout and grid-cols-3 creates three columns.

Task 3 – Answer

Create a responsive grid layout.


<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4 p-4">

  <div class="bg-purple-300 p-6">1</div>
  <div class="bg-purple-300 p-6">2</div>
  <div class="bg-purple-300 p-6">3</div>
  <div class="bg-purple-300 p-6">4</div>
  <div class="bg-purple-300 p-6">5</div>
  <div class="bg-purple-300 p-6">6</div>

</div>

Responsive behavior:

  • grid-cols-1 → Mobile (1 column)
  • md:grid-cols-2 → Tablet (2 columns)
  • lg:grid-cols-3 → Laptop (3 columns)

Task 4 – Answer

Create a parent container with relative and place a box at the top-right.


<div class="relative h-40 bg-gray-200 p-4">

  <div class="absolute top-0 right-0 bg-red-400 p-2">
  Top Right
  </div>

</div>

The parent container uses relative. The child box uses absolute with top-0 and right-0 to position it at the top-right corner.
