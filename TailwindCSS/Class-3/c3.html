3. Background Images & Gradients

Background Image

Background images allow developers to place images behind content. In modern Tailwind (JIT mode), we can use the bg-[url()] utility to directly add a background image without writing inline CSS. 


<div class="h-40 bg-[url('image.jpg')] bg-cover bg-center">
</div>

Background Size

Controls how the background image fits inside the container. 


bg-cover    /* fills container (may crop) */
bg-contain  /* fits image fully (no crop) */
bg-auto     /* original size */

Background Position

Controls where the image is positioned inside the container. 


bg-center
bg-top
bg-bottom
bg-left
bg-right

Background Repeat

Controls whether the background image repeats. 


bg-repeat
bg-no-repeat
bg-repeat-x
bg-repeat-y

Gradient Background

Gradients allow you to smoothly transition between two or more colors. In Tailwind CSS, gradients are created using three main utilities: gradient direction, starting color, and ending color.

The class bg-gradient-to-r means the gradient will move from left to right. The class from-blue-500 defines the starting color, and to-purple-500 defines the ending color.

Together these classes create a smooth transition from blue to purple across the element's background. 


bg-gradient-to-r
from-blue-500
to-purple-500


<div class="bg-gradient-to-r from-blue-500 to-purple-500 text-white p-6">
Gradient Background
</div>
Gradient Background

Tailwind also supports other gradient directions such as bg-gradient-to-l (right to left), bg-gradient-to-t (bottom to top), and bg-gradient-to-b (top to bottom).

4. Object Fit

The object-fit utility controls how an image or video fits inside a fixed container. When width and height are set, the image may need to scale, crop, or stretch to fit the container. Tailwind provides several utilities to control this behavior.

Object Fit Utilities 


object-cover
object-contain
object-fill
object-none
object-scale-down

object-cover – The image fills the entire container while maintaining its aspect ratio. Some parts of the image may be cropped.

object-contain – The entire image is visible inside the container while maintaining the aspect ratio. Empty space may appear around the image.

object-fill – The image stretches to fill the container completely. The aspect ratio is not preserved, so the image may look distorted.

object-none – The image keeps its original size and does not scale to fit the container.

object-scale-down – The image behaves like object-contain or object-none, whichever results in the smaller image.

Example 


<img src="image.jpg" class="w-80 h-48 object-cover">

5. Transform & Scale

Transform utilities allow you to visually change the position, size, rotation, or shape of an element. They are widely used for animations, hover effects, interactive UI, and modern designs.

Scale (Resize)

Scale changes the size of an element. Values above 100 increase size, below 100 decrease size. 


<div class="hover:scale-90 transition duration-300">Shrink</div>
<div class="hover:scale-110 transition duration-300">Grow</div>
Shrink
Grow

Rotate

Rotate spins the element clockwise or counterclockwise. 


<div class="hover:rotate-45 transition duration-300">Rotate</div>
<div class="hover:-rotate-45 transition duration-300">Reverse</div>
Rotate
Reverse

Translate (Move)

Translate moves the element along X or Y axis without affecting layout. 


<div class="hover:translate-y-4 transition duration-300">Down</div>
<div class="hover:-translate-y-4 transition duration-300">Up</div>
Down
Up

Skew

Skew tilts the element along X or Y axis. 


<div class="hover:skew-x-6 transition duration-300">Skew X</div>
<div class="hover:skew-y-6 transition duration-300">Skew Y</div>

Skew Y

Controls the starting point of transformation.

6. Transitions

Transitions allow elements to change styles smoothly instead of instantly. They are commonly used with hover, focus, and interactive UI effects to improve user experience.

Transition Utilities 


transition
transition-all
transition-colors
transition-opacity
transition-transform
  • transition → Default transition (most commonly used)
  • transition-all → Applies transition to all properties
  • transition-colors → Only colors (text, bg, border)
  • transition-opacity → Only opacity changes
  • transition-transform → Only scale, rotate, translate

Duration 


duration-75
duration-150
duration-300
duration-500
duration-700
duration-1000

Controls how long the animation takes. 300ms is the most commonly used for UI.

Timing Function (Easing) 


ease-linear
ease-in
ease-out
ease-in-out
  • ease-linear → constant speed
  • ease-in → slow start
  • ease-out → slow end
  • ease-in-out → smooth start & end

Delay 


delay-75
delay-150
delay-300

Adds a delay before the transition starts.

Examples

Color Transition


<button class="transition-colors duration-300 hover:bg-blue-800">

Combined Effects

7. Hover & Focus States

Tailwind provides state modifiers that allow styles to change when a user interacts with an element. Two common states are:

  • hover: applies styles when the mouse pointer moves over an element.
  • focus: applies styles when an input field or element becomes active.

These states help create interactive UI elements like buttons, forms, and links. They also improve user experience by providing visual feedback.

Hover Example 


<button class="bg-green-600 hover:bg-green-700 text-white font-bold
py-3 px-6 rounded-xl transition">
Hover Button
</button>

When the user moves the mouse over the button, the background color changes from green-600 to green-700. The transition class makes the color change smooth.

Hover Scale Example 


<button class="bg-blue-600 text-white px-6 py-3 rounded-xl
transition hover:scale-105">
Hover Scale
</button>

Here the button slightly increases in size when hovered. This effect is created using hover:scale-105.

Focus Example 


<input
class="w-72 border-2 border-gray-200 p-4
focus:outline-none
focus:border-blue-500
focus:ring-4 focus:ring-blue-100
rounded-xl transition"
placeholder="Focus here">

When the user clicks or tabs into the input field:

  • focus:outline-none removes the default browser outline.
  • focus:border-blue-500 changes the border color.
  • focus:ring-4 adds a focus ring around the input.
  • focus:ring-blue-100 sets the ring color.
