Class 5 — Tailwind Workflow + Customization

1. Tailwind CLI Setup (Important Workflow)

Before using Tailwind customization we must install Tailwind CLI.

Step 1 — Initialize Project

npm init -y

Step 2 — Install Tailwind

npm install tailwindcss

Step 3 — Create Tailwind Config

npx tailwindcss init

This creates:

tailwind.config.js

Step 4 — Create input.css

@import "tailwindcss";

Step 5 — Build Tailwind CSS

npx tailwindcss -i ./input.css -o ./output.css --watch

This generates output.css.

Step 6 — Link CSS in HTML

<link rel="stylesheet" href="output.css">

2. @layer in Tailwind CSS

In Tailwind CSS, @layer is used to define where your custom styles should be placed within Tailwind’s styling system.

🔹 Tailwind Layers

Tailwind has 3 main layers:

  • base → Default/reset styles (like headings, body, etc.)
  • components → Reusable classes (like buttons, cards)
  • utilities → Small helper classes (like padding, margin, colors)
base → components → utilities

This order is important because later layers override earlier ones.

🔹 @layer components

Used to create reusable UI components like buttons, cards, inputs, etc.

Example (input.css)

@import "tailwindcss";

@layer components {
  .btn-primary {
    @apply bg-blue-500 text-white px-4 py-2 rounded;
  }
}

Usage

<button class="btn-primary">Submit</button>

🔹 @layer base

Used to define global styles like typography or reset styles. 

@layer base {
  h1 {
    @apply text-3xl font-bold;
  }
}

🔹 @layer utilities

Used to create custom utility classes. 

@layer utilities {
  .text-shadow {
    text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
  }
}

🔹 @apply in Tailwind

@apply is used to combine multiple Tailwind utility classes into a single custom class. 

.card {
  @apply bg-white shadow p-4 rounded-lg;
}

This helps reduce repetition and keeps HTML clean.

🔹 Why use @layer?

  • ✔ Ensures correct CSS order
  • ✔ Prevents style conflicts
  • ✔ Works with Tailwind's purge (removes unused CSS)
  • ✔ Keeps styles organized

🔹 Important Behavior

Utilities override components because they come later in the CSS order. 

<div class="card bg-black"></div>

Even if .card has bg-white, bg-black will override it.

🔹 Summary

  • @layer → defines where your styles belong
  • @apply → combines utility classes
  • components → reusable styles
  • utilities → override styles

3. Extending Theme

Theme extension allows adding custom colors, fonts, spacing etc.

Tailwind v3 Method

In Tailwind v3 we extend inside the config file.

/* tailwind.config.js */

module.exports = {
 theme:{
  extend:{
   colors:{
    primary:"#ff4d4d"
   }
  }
 }
}
Usage: 
<button class="bg-primary text-white p-2">Click</button>

Tailwind v4 Method

Tailwind v4 uses CSS based configuration using @theme.

Example (input.css): 
@import "tailwindcss";

@theme{
 --color-primary:#ff4d4d;
}
Usage: 
<button class="bg-primary text-white p-2">Click</button>

5. Dark Mode

Tailwind supports dark mode in two ways.

Method 1 — Media Strategy

Automatically follows system theme.

darkMode:"media"

Method 2 — Class Strategy

Dark mode activates when dark class is added.

darkMode:"class"
Example: 
<html class="dark">

<body class="bg-white dark:bg-gray-800 dark:text-white">
Dark Mode Example
</body>

Important Note (Tailwind v4)

When using Tailwind v4 with CSS configuration we must add the dark variant manually.

Example: 
@import "tailwindcss";

/* enable dark mode */
@custom-variant dark (&:where(.dark, .dark *));

6. Container Queries (Optional)

Container queries allow components to respond to the size of their parent container.

Example: 
<div class="@container border p-4 overflow-auto resize-x w-[300px]">
  <div class="p-4 bg-red-200 
              @sm:bg-yellow-200 
              @md:bg-blue-200 
              @lg:bg-green-200">
    Container Responsive Content
  </div>
</div>

  • Create tailwind.config.js

  • Run Tailwind build command
  • Use @layer for reusable components
  • Use @apply to avoid repeating utilities
  • Tailwind v3 uses config for extending theme
  • Tailwind v4 uses @theme in CSS
  • Dark mode requires class strategy
