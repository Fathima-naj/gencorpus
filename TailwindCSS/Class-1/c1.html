Tailwind CSS - Introduction

1. What is Tailwind?

Tailwind CSS is a utility-first CSS framework used to build modern user interfaces quickly. Instead of writing custom CSS classes, Tailwind provides small reusable utility classes that directly control styling.

Utility-first means we style elements using small classes instead of writing large CSS files.

Example without Tailwind


.button{
background-color:blue;
color:white;
padding:10px;
border-radius:5px;
}

Example with Tailwind


<button class="bg-blue-500 text-white p-2 rounded">
Click Me
</button>
  • bg-blue-500 → background color
  • text-white → text color
  • p-2 → padding
  • rounded → border radius

Why Developers Use Tailwind

  • Faster UI development
  • No need to switch between HTML and CSS files
  • Consistent design system
  • Built-in responsive utilities
  • Perfect for modern frameworks like React and Vue

2. Installing Tailwind

Using CDN (Beginner Method)

The easiest way to use Tailwind is by adding the CDN link.


<script src="https://cdn.tailwindcss.com"></script>
Example: 

<!DOCTYPE html>
<html>
<head>
<script src="https://cdn.tailwindcss.com"></script>
</head>

<body>

<h1 class="text-3xl font-bold text-blue-600">
Hello Tailwind
</h1>

</body>
</html>
CDN is useful for learning but not recommended for production websites.

Proper Setup (PostCSS / Vite)

Steps:
  • Install Node.js
  • Create project using Vite / React
  • Install Tailwind

npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
Add Tailwind directives to CSS: 

@tailwind base;
@tailwind components;
@tailwind utilities;

3. Tailwind Config File

The configuration file is: tailwind.config.js Example: 

module.exports = {
content: ["./index.html"],
theme: {
extend: {},
},
plugins: [],
}
Explanation:
  • content → files that contain Tailwind classes
  • theme → customize design values
  • extend → extend default styles
  • plugins → add extra features

6. Typography Utilities

Typography utilities in Tailwind CSS control text appearance, alignment, spacing, and behavior.

1. Font Size

Font size utilities control the size of the text. Tailwind provides a predefined scale from extra small to very large headings.

  • text-xs → Extra small text (12px)
  • text-sm → Small text (14px)
  • text-base → Default text size (16px)
  • text-lg → Large text (18px)
  • text-xl → Extra large text (20px)
  • text-2xl → text-9xl → Heading sizes (24px to very large display text)

These classes follow a consistent scale, making it easy to maintain visual hierarchy in your design.

12. White Space

  • whitespace-normal → Default behavior. Text wraps normally and extra spaces are removed.
  • whitespace-nowrap → Prevents text from wrapping. All text stays on a single line.
  • whitespace-pre → Preserves spaces and line breaks exactly as written, but does not wrap text.
  • whitespace-pre-line → Preserves line breaks but removes extra spaces. Text wraps normally.
  • whitespace-pre-wrap → Preserves both spaces and line breaks, and also allows text to wrap.

8. Responsive Prefixes

Tailwind supports responsive design using prefixes. Breakpoints:
  • sm: small devices
  • md: tablets
  • lg: laptops
  • xl: desktops
Example: 

<div class="bg-red-500 md:bg-blue-500 lg:bg-green-500 p-4 text-white">
Responsive Box
</div>
Explanation:
  • Mobile → red
  • Tablet → blue
  • Desktop → green
