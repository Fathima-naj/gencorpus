Width & Height

These properties are used to control the size of an element.

  • width → Sets the horizontal size of an element.
  • height → Sets the vertical size of an element.
  • max-width → Defines the maximum width. The element will not grow beyond this.
  • max-height → Defines the maximum height. The element will not grow beyond this.
width: 200px;
height: 100px;
max-width: 100%;
max-height: 120px;

Difference: Width vs Max-Width & Height vs Max-Height

These properties control the size of elements, but they behave differently.

🔹 Width vs Max-Width

  • width → Sets a fixed width. The element will always try to stay this size.
  • max-width → Sets the maximum width. The element can shrink but will not exceed this value.
width: 300px;
max-width: 300px;
Width: Fixed (may overflow on small screens)
Max-Width: Flexible (adjusts to screen size)

🔹 Height vs Max-Height

  • height → Sets a fixed height. The element will always stay this height.
  • max-height → Sets the maximum height. The element can grow but not beyond this limit.
height: 100px;
max-height: 100px;
overflow: auto;

Even if content is small or large
Max-Height: Grows until 100px

Summary

  • width / height → Fixed size (strict)
  • max-width / max-height → Flexible with limit (responsive)

Object Fit

The object-fit property controls how an image or video fits inside its container.

  • fill → Default. Stretches image to fill the container (may distort).
  • contain → Fits the entire image inside the box (no crop, may leave empty space).
  • cover → Fills the box while maintaining aspect ratio (image may be cropped).
  • none → Keeps original size (may overflow).
  • scale-down → Chooses smaller of none or contain.
object-fit: fill;
object-fit: contain;
object-fit: cover;
object-fit: none;
object-fit: scale-down;

Box Shadow

The box-shadow property adds shadow effects around an element.

🔹 Syntax

box-shadow: h-offset v-offset blur spread color;
  • h-offset → Horizontal shadow (left/right)
  • v-offset → Vertical shadow (top/bottom)
  • blur → Blur radius (higher = softer shadow)
  • spread → Expands or shrinks shadow size
  • color → Shadow color

🔹 Basic Example

box-shadow: 2px 2px 10px gray;
Basic Shadow

🔹 With Spread

box-shadow: 2px 2px 10px 5px gray;
Shadow with Spread

🔹 Multiple Shadows

box-shadow: 2px 2px 5px red, -2px -2px 5px blue;
Multiple Shadows

🔹 Inset Shadow (Inside)

box-shadow: inset 2px 2px 10px gray;
Inset Shadow

Overflow

The overflow property controls what happens when content is too big to fit inside a container.

🔹 Values

  • visible → Default. Content overflows outside the box.
  • hidden → Extra content is clipped (not visible).
  • scroll → Scrollbars always appear.
  • auto → Scrollbars appear only when needed.
overflow: visible | hidden | scroll | auto;

🔹 overflow: visible (default)

This is long content that overflows outside the box.

🔹 overflow: hidden

This is long content that gets cut off and not visible.

🔹 overflow: scroll

This is long content that shows scrollbars always.

🔹 overflow: auto

This is long content. Scroll appears only when needed.

🔹 overflow-x and overflow-y

Used to control horizontal and vertical overflow separately.

overflow-x: hidden;
overflow-y: scroll;
This is a very long content that will only scroll vertically and not horizontally. More text... More text... More text...

Summary

  • visible → overflow outside
  • hidden → cut content
  • scroll → always scrollbars
  • auto → smart scroll

Transition

The transition property is used to create smooth animation when a CSS property changes.

Without transition, changes happen instantly. With transition, they happen gradually.

🔹 Syntax

transition: property duration timing-function delay;
  • property → Which CSS property to animate (e.g., background, width, transform)
  • duration → How long the animation takes (e.g., 0.5s, 1s)
  • timing-function → Speed style of animation
  • delay → Wait time before animation starts

🔹 1. Basic Transition

This creates a smooth color change on hover.

button {
  background: blue;
  transition:background-color 0.5s ease;
}

button:hover {
  background: red;
}

👉 Here, the background changes smoothly in 0.5 seconds.

🔹 2. Transition Specific Property

Instead of applying transition to all properties, you can target only one.

transition: background 0.5s;

👉 Only the background will animate, other properties change instantly.

🔹 3. Multiple Properties

You can animate more than one property at the same time.

transition: all 0.5s;

👉 Color changes + button grows smoothly.

Transition Timing Functions

The timing-function defines the speed curve of the transition.

  • ease → slow start, fast middle, slow end (default)
  • linear → constant speed
  • ease-in → slow start
  • ease-out → slow end
  • ease-in-out → slow start and end

🔹 Syntax

transition: property duration timing-function;

🔹 Examples

ease
linear
ease-in
ease-out
ease-in-out

👉 Movement starts slow → speeds up → slows down again.

🔹 5. Delay

Adds waiting time before animation starts.

transition: transform 1s;
transition-delay: 1s;
Delay

👉 Animation starts after 1 second delay.

🔹 6. Important Notes

  • Transition works only when a property changes (like hover, focus, etc.)
  • Not all properties are animatable (e.g., display cannot be animated)
  • Most commonly used with hover effects

Summary

  • transition → controls animation
  • duration → how long
  • timing → speed style
  • delay → when to start

Transform

The transform property is used to move, rotate, scale, or skew elements.

🔹 Values

  • scale() → Resize element
  • translate() → Move element
  • rotate() → Rotate element
  • skew() → Skew element

🔹 Scale

transform: scale(1.2);

🔹 Translate

transform: translate(50px, 20px);

🔹 Rotate

transform: rotate(45deg);

🔹 Skew

transform: skew(20deg);

🔹 Multiple Transform

transform: scale(1.2) rotate(45deg);

🔹 Transform with Translate + Transition

  .box {
  width: 150px;
  height: 150px;
  background-color: blue;

  /* Apply transition */
  transition: background-color 0.5s ease, transform 0.5s ease;
}

.box:hover {
  background-color: red;

  /* Move element to right */
  transform: translateX(100px);
}
