Animation & Keyframes

CSS animations are used to create movement and visual effects.

🔹 Basic Syntax

  @keyframes animationName {
  from { property: value; }
  to { property: value; }
}

.element {
animation: animationName duration timing-function delay iteration direction fill-mode;
}

🔹 Basic Example

@keyframes move {
  from { transform: translateX(0); }
  to { transform: translateX(100px); }
}

.box {
animation: move 2s infinite;
}

🔹 Multiple Steps

  @keyframes move {
  0%   { transform: translateX(0); background: red; }
  50%  { transform: translateX(100px); background: blue; }
  100% { transform: translateX(0); background: green; }
}

🔹 Animation Properties

  • animation-name → Name of keyframes
  • animation-duration → Time (e.g., 2s)
  • animation-delay → Delay before start
  • animation-iteration-count → Number / infinite
  • animation-direction → normal, reverse, alternate
  • animation-timing-function → ease, linear, ease-in, ease-out
  • animation-fill-mode → forwards, backwards, both

🔹 Timing Functions

animation-timing-function: ease;
animation-timing-function: linear;
animation-timing-function: ease-in;
animation-timing-function: ease-out;
animation-timing-function: ease-in-out;

🔹 Direction

animation-direction: reverse;

🔹 Iteration Count

animation-iteration-count: 3;
animation-iteration-count: infinite;

🔹 Delay

🔹 Fill Mode

animation-fill-mode: backwards;

🔹 Shorthand

animation: move 2s ease 1s infinite alternate forwards;

🔹 Summary

Animation defines movement over time using keyframes.
Keyframes define the steps, and animation properties control the behavior.
