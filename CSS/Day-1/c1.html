Introduction to CSS - Part 1

1. What is CSS?

CSS stands for Cascading Style Sheets. It is used to control the design, layout, colors, fonts of a webpage.

  • Separates content (HTML) from design (CSS)
  • Improves website appearance
  • Supports responsive design

2. Inline CSS

This text is styled using Inline CSS.

Inline CSS is written inside the HTML element using the style attribute.

Disadvantage: Not reusable, hard to maintain

3. Internal / Embedded CSS

CSS is written inside the <style> tag in the <head> section.

Best for small projects or single page styling.

4. External CSS

CSS is written in a separate .css file and linked using the <link> tag.

  • Reusable across multiple pages
  • Cleaner HTML code
  • Best practice for real projects

🔹 Border Radius (Rounded Corners)

Rounded Corners

The border-radius property is used in CSS to create rounded corners for elements like divs, buttons, images, and more.

📌 Basic Syntax

 border-radius: value;
  • value can be in px, %, etc.

📌 Examples

1. Same radius for all corners 
 border-radius: 10px;
2. Different radius for each corner 
 border-radius: 10px 20px 30px 40px;
  • Top-left → 10px
  • Top-right → 20px
  • Bottom-right → 30px
  • Bottom-left → 40px
3. Make a circle 
 border-radius: 50%;

When width and height are equal, 50% creates a perfect circle.

📌 Individual Corner Control

 border-top-left-radius: 10px; border-top-right-radius: 20px; border-bottom-right-radius: 30px; border-bottom-left-radius: 40px;

📌 Real-world Uses

  • Buttons with smooth edges
  • Cards and UI components
  • Profile images (circle avatars)
  • Modern website design

🔹 Box Model Concept (Important)

Every element in CSS follows the box model:

  • Content → actual text
  • Padding → space inside the box
  • Border → outline
  • Margin → space outside the box

7. Different Ways to Define Colors

1. Color Names

Example: red, blue, green

Colors can be defined using predefined names provided by CSS. There are around 140+ standard color names (like red, blue, green, black). It is the simplest way to apply colors but offers limited variety.

2. Hexadecimal

Example: #3498db

HEX (Hexadecimal) colors are defined using a 6-digit code starting with #. Format: #RRGGBB

  • RR → Red (00 to FF)
  • GG → Green (00 to FF)
  • BB → Blue (00 to FF)

Example: #000000 → black, #ffffff → white

3. RGB

Example: rgb(255,0,0)

RGB stands for Red, Green, Blue. Each value ranges from 0 to 255.

  • rgb(255,0,0) → red
  • rgb(0,255,0) → green
  • rgb(0,0,255) → blue

This method allows mixing of colors using numeric values.

4. RGBA

Example with transparency

RGBA is similar to RGB but includes an extra value called Alpha (opacity).

  • 0 → fully transparent
  • 1 → fully visible

Example: rgba(255,0,0,0.5) → semi-transparent red

5. HSL

Example: hsl(120,100%,25%)

HSL stands for Hue, Saturation, and Lightness.

  • Hue → type of color (0–360 degrees on color wheel)
  • Saturation → intensity (0% = gray, 100% = full color)
  • Lightness → brightness (0% = black, 100% = white)

Example: hsl(0,100%,50%) → red

6. HSLA

Example with transparency

HSLA is similar to HSL but includes an Alpha value for transparency.

  • Alpha ranges from 0 to 1

Example: hsla(200,100%,50%,0.5) → semi-transparent blue

8. CSS Selector using ID

The ID selector is used to target a specific HTML element using its unique id attribute.

It is written using the # (hash) symbol followed by the id name.

This paragraph is styled using ID selector (#box)

🔹 Syntax

#idName {
    property: value;
}

🔹 Example CSS

#box {
    color: white;
    background-color: black;
    padding: 10px;
}

🔹 Important Points

  • ID must be unique (used only once per page)
  • Used for styling a specific element
  • Has higher priority than class selector
  • ID name should not start with a number

🔹 How it Works

The browser finds the element with the matching id and applies the styles defined using #id.

9. CSS Priority

  • Inline CSS → Highest priority
  • Internal CSS → Medium
  • External CSS → Lowest

Example: If same style is applied, inline will override others.
