CSS Grid

🔹 What is CSS Grid?

CSS Grid is a two-dimensional layout system used to create layouts using rows and columns. It is powerful, flexible, and widely used in modern web design.

🔹 Basic Grid

display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 10px;

🔹 Grid Tracks (Rows & Columns)

  • grid-template-columns → defines columns
  • grid-template-rows → defines rows
  • fr → fraction of available space

🔹 Grid Item Spanning

grid-column: span 2;
grid-row: span 2;

Allows items to occupy multiple rows or columns.

🔹 Alignment in Grid

In CSS Grid, alignment is used to control how items are positioned inside each grid cell (horizontally and vertically).

🔸 justify-items (Horizontal Alignment)

  • Controls alignment from left → right
  • Works on inline axis

Values:

  • start → align left
  • end → align right
  • center → center horizontally
  • stretch → fill full width (default)
.grid-align {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  justify-items: center;
}

👉 Items will be centered horizontally inside each cell

🔸 align-items (Vertical Alignment)

  • Controls alignment from top → bottom
  • Works on block axis

Values:

  • start → align top
  • end → align bottom
  • center → center vertically
  • stretch → fill full height (default)
.grid-align {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  height: 200px;
  align-items: center;
}

👉 Items will be centered vertically inside each cell

🔸 place-items (Shorthand)

  • Shorthand for align-items + justify-items

Syntax:

place-items: align-items justify-items;

Example:

.grid-align {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  height: 200px;
  place-items: center;
}

👉 This centers items both horizontally and vertically

🔹 Auto-Fit & Minmax

grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));

Automatically adjusts number of columns based on screen size.

🔹 Grid Auto Flow

grid-auto-flow: row;
grid-auto-flow: column;

Controls how items are automatically placed.

🔹 Grid Template Areas

grid-template-areas:
"header header header"
"sidebar content content"
"footer footer footer";

🔹 Layout Use Case

  • Header → top section
  • Sidebar → navigation
  • Content → main section
  • Footer → bottom

🔹 Important Concepts

  • Grid = 2D layout (rows + columns)
  • Flexbox = 1D layout
  • Auto-fit makes layout responsive
  • Minmax controls size limits

📌 Summary

  • display: grid activates grid
  • grid-template-columns defines structure
  • gap adds spacing
  • grid-column / grid-row controls size
  • auto-fit + minmax creates responsive grids
  • grid-template-areas creates layouts
