📘 Introduction to CSS - Part 4

🔹 Media Queries

Media Queries are a feature in CSS used to create responsive web design. They allow a webpage to adapt its layout, colors, fonts, and structure based on different screen sizes, resolutions, and device types such as mobile, tablet, and desktop.

Without Media Queries, a website designed for desktop may look broken or too large on smaller screens. Using Media Queries ensures a smooth user experience across all devices.

🔸 Why Media Queries are Important?

  • Makes websites mobile-friendly
  • Improves user experience on different devices
  • Helps create flexible and adaptive layouts
  • Essential for modern web development

🔸 Syntax

@media (condition){
    /* CSS rules */
}

The CSS inside the media query will only apply when the given condition is true.

🔸 Types of Conditions

  • max-width → Applies styles when screen is smaller than given width
  • min-width → Applies styles when screen is larger than given width
  • orientation → Checks if device is portrait or landscape
  • resolution → For high-resolution screens

🔸 Example

In this example, the background color changes based on screen size: 

/* Desktop */
.media-box{
    background: green;
}

/* Tablet */
@media (max-width: 768px){
    .media-box{
        background: orange;
    }
}

/* Mobile */
@media (max-width: 480px){
    .media-box{
        background: red;
    }
}
Resize the screen to see color change
  • Desktop: Green (Default style)
  • Tablet: Orange (Screen ≤ 768px)
  • Mobile: Red (Screen ≤ 480px)

🔸 Common Breakpoints

Breakpoints are specific screen sizes where the layout changes.

  • Mobile → max-width: 480px
  • Large Mobile → max-width: 600px
  • Tablet → max-width: 768px
  • Laptop → max-width: 1024px
  • Desktop → min-width: 1025px

🔸 Mobile First vs Desktop First

1. Mobile First Approach:

  • Start designing for mobile devices
  • Use min-width to scale up
/* Mobile */
.box{
    font-size: 14px;
}

/* Tablet & above */
@media (min-width: 768px){
    .box{
        font-size: 18px;
    }
}

2. Desktop First Approach:

  • Start designing for desktop
  • Use max-width to scale down

🔸 Multiple Conditions

@media (max-width: 768px) and (orientation: portrait){
    body{
        background: lightblue;
    }
}

This applies styles only when both conditions are true.

🔸 Real Use Cases

  • Changing layout from grid to single column
  • Adjusting font size for readability
  • Hiding/showing elements on mobile
  • Making navigation responsive (hamburger menu)

🔸 Summary

  • Media Queries make websites responsive
  • They apply CSS based on screen conditions
  • Common properties: max-width, min-width
  • Breakpoints control layout changes
  • Two approaches: Mobile First & Desktop First

🔹 Flexbox with Media Queries

Flexbox is a one-dimensional layout system used to arrange items in a row or column. When combined with Media Queries, it becomes very powerful for building responsive layouts.

🔸 Flex Container

display: flex;

🔸 Example

In this example, items are displayed in a row on desktop and change to column on mobile. 

.flex-container{
    display: flex;
    gap: 10px;
}

.flex-item{
    background: #e67e22;
    color: white;
    padding: 20px;
    flex: 1;
    text-align: center;
}

/* Mobile */
@media (max-width: 768px){
    .flex-container{
        flex-direction: column;
    }
}

  • Desktop → Items in row
  • Mobile → Items in column

🔸 Explanation

  • display: flex → Activates flexbox
  • flex-direction: row (default) → Horizontal layout
  • flex-direction: column → Vertical layout
  • gap → Space between items
  • flex: 1 → Equal width for all items

🔸 Real Use Cases

  • Responsive navigation bars
  • Card layouts
  • Aligning items horizontally or vertically
  • Switching layout direction on smaller screens

🔹 CSS Grid (Starting)

CSS Grid is a powerful two-dimensional layout system used to design web pages with rows and columns. It allows developers to control both horizontal and vertical alignment at the same time, making it more flexible than traditional layouts.

It is mainly used for creating complex layouts like dashboards, galleries, and responsive designs.

🔸 Grid Container

display: grid;

When you apply display: grid to a parent element, it becomes a grid container, and all its child elements become grid items.

🔸 Grid Columns

grid-template-columns: repeat(3, 1fr);

This creates 3 equal columns using the fr (fraction unit).

  • 1fr → takes 1 part of available space
  • repeat(3, 1fr) → creates 3 equal columns

🔸 Grid Rows

grid-template-rows: auto;

Defines the height of rows. auto means rows adjust based on content size.

🔸 Gap

gap: 10px;

Adds space between rows and columns.

  • row-gap → space between rows
  • column-gap → space between columns

🔸 How Responsive Grid Works

Using Media Queries, we change the number of columns based on screen size: 

/* Desktop */
grid-template-columns: repeat(3, 1fr);

/* Tablet */
@media (max-width: 768px){
    grid-template-columns: repeat(2, 1fr);
}

/* Mobile */
@media (max-width: 480px){
    grid-template-columns: 1fr;
}

This ensures the layout adapts smoothly across devices.

🔸 Important Concepts

  • Grid = 2D layout (rows + columns)
  • Flexbox = 1D layout (row OR column)
  • fr unit divides available space
  • Grid is best for full-page layouts

🔸 Real Use Cases

  • Dashboard layouts
  • Image galleries
  • Card-based UI designs
  • Responsive website structures

📌 Summary

  • Media Queries → Used for responsive design
  • Breakpoints → Control layout at different screen sizes
  • CSS Grid → Creates row & column layout
  • fr unit → Divides available space
  • Responsive Grid → Changes columns based on screen
  • Grid is a 2D layout system (rows + columns)
