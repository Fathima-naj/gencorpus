🔹 CSS Position

CSS position property is used to control how an element is placed in a webpage layout. It defines whether an element stays in normal flow or moves relative to other elements.

  • static (default)
  • relative
  • absolute
  • fixed
  • sticky

1. Position Relative

This box is relative (moves from its normal position)

position: relative; moves an element relative to its original (normal) position.

  • The element still occupies its original space
  • It can be moved using top, left, right, bottom
  • Other elements are NOT affected by its movement

Example: top: 10px; moves it down left: 20px; moves it right

2. Position Absolute

Parent
Absolute Box

position: absolute; removes the element from normal document flow.

  • It is positioned relative to the nearest positioned parent (not static)
  • If no parent is positioned, it uses the body
  • Other elements behave as if this element does not exist

⚠️ Important: Parent must have position: relative for proper control.

Used for:

  • Tooltips
  • Dropdowns
  • Custom UI positioning

3. Position Fixed

Fixed Box

position: fixed; positions an element relative to the viewport (screen).

  • It stays fixed even when scrolling
  • Does NOT move with page content
  • Removed from normal flow

Common use cases:

  • Navigation bars
  • Chat buttons
  • "Back to Top" buttons

4. Position Sticky

Sticky Header

position: sticky; is a combination of relative + fixed.

  • Acts like relative initially
  • Becomes fixed when scroll reaches a specified position
  • Requires top, left, right or bottom value

Example: top: 0; makes it stick to the top when scrolling

Common use:

  • Sticky headers
  • Sidebar menus

📌 Quick Comparison

Property Behavior
relative Moves from original position
absolute Moves relative to parent
fixed Stays fixed on screen
sticky Switches between relative and fixed

🔹 CSS Units

CSS units define the size of elements such as width, height, margin, padding, and font-size. They are mainly divided into:

  • Absolute Units (fixed size)
  • Relative Units (flexible and responsive)

1. Absolute Unit (px)

Width: 200px

px (pixels) is the most commonly used absolute unit.

  • It represents a fixed size on the screen
  • Does NOT change based on screen size
  • Used when exact control is needed

Example: width: 200px; → always remains 200 pixels

⚠️ Not fully responsive for different devices.

2. Relative Units

Relative units are flexible and adjust based on screen size or parent elements. They are important for responsive design.

% (Percentage)

Width: 50%

% is relative to the parent element.

  • 50% means half of parent width
  • Changes when parent size changes

Example: If parent width = 400px → 50% = 200px

em

Parent text (2em text)

em is relative to the parent element’s font-size.

  • 1em = parent font size
  • 2em = 2 × parent size

Example: Parent = 20px → 2em = 40px

⚠️ Can cause nested scaling issues (sizes keep increasing if deeply nested)

rem

1.5 rem text (based on root html size)

rem (root em) is relative to the root (html) font-size.

  • Default root size = 16px
  • 1rem = 16px
  • 1.5rem = 24px

✅ Better than em because it avoids nesting problems

vw & vh

50vw width & 20vh height

vw (viewport width) and vh (viewport height) are based on screen size.

  • 1vw = 1% of screen width
  • 1vh = 1% of screen height

Example:

  • 50vw = 50% of screen width
  • 20vh = 20% of screen height

Used for:

  • Full-screen layouts
  • Responsive sections

📌 Quick Comparison

Unit Type Based On
px Absolute Fixed size
% Relative Parent element
em Relative Parent font-size
rem Relative Root (html)
vw Relative Viewport width
vh Relative Viewport height

✅ Best Practice

  • Use px for borders and small fixed elements
  • Use rem for font sizes (recommended)
  • Use % for layouts
  • Use vw/vh for full-screen design

🔹 Flexbox

Flexbox (Flexible Box Layout) is a layout system used to design flexible and responsive layouts easily. It works in one direction: row (horizontal) or column (vertical).

🔸 Flex Container

1
2
3

To start using Flexbox, set:

display: flex;
  • Parent becomes flex container
  • Children become flex items

🔸 Flex Direction

flex-direction defines the direction of items.

  • row (default) → left to right
  • row-reverse
  • column → top to bottom
  • column-reverse

Example: flex-direction: column;

🔸 Main Axis vs Cross Axis

  • Main Axis → direction of flex-direction
  • Cross Axis → perpendicular to main axis

Example:

  • row → main axis = horizontal
  • column → main axis = vertical

🔸 Gap

Adds space between flex items.

  • gap: 10px;
  • Works like margin but cleaner

🔸 Flex Item Properties

1. flex-grow

Defines how much an item grows compared to others.

  • flex-grow: 1; → takes available space

2. flex-shrink

Defines how items shrink when space is less.

  • flex-shrink: 1; (default)

3. flex-basis

Initial size before growing/shrinking.

  • flex-basis: 200px;

4. flex (shortcut)

Shorthand for:

flex: grow shrink basis;

Example: flex: 1;

🔸 Align Self

Overrides align-items for individual item.

  • align-self: center;

🔸 Order

Changes order of items without changing HTML.

  • order: 1;
  • Default = 0
