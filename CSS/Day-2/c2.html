Introduction to CSS - Part 2

🔹 Basic CSS Selectors

Selectors are used to target HTML elements and apply styles to them. They tell the browser “which element should get the style”.

🔹 Universal Selector (*)

The universal selector selects all elements on the page. It is mostly used to remove default spacing.

* { margin: 0; padding: 0; }

Example:

This paragraph

This heading

This span

🔹 ID Selector (#)

The ID selector targets a unique element. Each ID should be used only once in a page.

#header { color: red; }

Example:

This is a header

🔹 Class Selector (.)

The class selector is used to target multiple elements. You can reuse the same class many times.

.box { background: yellow; }

Example:

Box 1

Box 2

🔹 Type / Element Selector

This selector targets elements using their tag name.

p { color: blue; }

Example:

This will be blue

This will also be blue

🔹 Attribute Selectors

Attribute selectors target elements based on their HTML attributes. Very useful in forms and dynamic UI.

1. Required Attribute

Selects inputs that have the required attribute.

input[required] { border: 2px solid red; }

Example:

2. Exact Value

Selects elements where attribute value exactly matches.

input[flag="orange"] { background: orange; }

Example:

3. Contains Letters (*=)

Selects elements whose attribute contains specific letters.

input[flag*="white"] { color: red; }

Example:

4. Contains Word (~=)

Selects elements where the attribute contains a specific word (space-separated).

input[eligible~="violet"] { border: 2px solid violet; }

Example:

5. Starts With (^=)

Selects elements whose attribute value starts with given text.

input[colors^="red"] { background: pink; }

Example:

6. Ends With ($=)

Selects elements whose attribute value ends with given text.

input[colors$="green"] { background: lightgreen; }

Example:

🔹 Hover Selector (:hover)

Applies style when user moves mouse over element.

button:hover { background: green; }

🔹 Combinator Selectors

Combinator selectors are used to define the relationship between elements. They help you target elements based on their position inside other elements.

1. Descendant Selector (space)

This selector targets all matching elements inside a parent, no matter how deeply nested.

.div1 div { color: blue; }

Meaning:

👉 Select all <div> elements that are inside .div1 (child, grandchild, etc.)

Working Example:

Direct Child (Blue)
Nested Child (Also Blue)

2. Child Selector (>)

This selector targets only direct children, not nested elements.

.div1 > div { color: red; }

Meaning:

👉 Select only the immediate <div> children of .div1

Working Example:

Direct Child (Red)
Nested Child (NOT affected)

🔸 Difference Between Descendant and Child

Selector What it selects
.div1 div All divs inside (any level)
.div1 > div Only direct children

👉 Easy Trick:
- Space = “any level inside”
- > = “only direct child”

🔹 CSS Specificity

Specificity decides which CSS rule is applied when multiple rules target the same element.

  • Inline Style → Highest priority
  • ID Selector (#) → High priority
  • Class / Attribute / Pseudo-class → Medium
  • Element Selector → Low
#id { color: red; } /* Higher priority */ .class { color: blue; } /* Lower than ID */ p { color: green; } /* Lowest */

👉 If multiple rules apply, the one with higher specificity wins.
